# 可行动事务 Agent · 概念宣传片说明

导航：[[docs/可行动事务Agent-00-总览|文档总览]] · [[docs/06-讲解视频/可行动事务Agent-讲解视频说明|讲解视频说明]] · [[docs/01-产品方案/可行动事务Agent-参赛主线方案|参赛主线方案]]

## 1. 成片

- 视频：`output/文启-概念宣传片.mp4`，1920×1080，30fps，84秒，H.264 + AAC，无旁白。
- 风格：海报式动态排版。配色和三块积木图标取自[[docs/05-交互Demo/可行动事务Agent-文启高保真Demo.html|文启流程可视化]]（深绿、浅绿、纸白），另加朱橙作为警示色；宋体大标题，叠加胶片颗粒，用五色百叶完成转场。
- 配乐：用程序合成的 96 BPM 极简电子乐，重击落在品牌亮相、「本次不能用」印章、竞品段回归这几个画面关键点上。没有使用外部素材，生成时不联网。
- 与旧讲解视频的区别：旧片约2分钟，有旁白，仍用旧名「旁批」；这一版用新名「文启」，靠画面和节奏传达，适合当开场或背景循环。

## 2. 分镜

| 时间 | 场景 | 画面 | 对原型的提示 |
|---|---|---|---|
| 0–7.5s | 又一份通知 | 18份文件按半拍砸落，未读计数跳到129，盖上「读不过来」 | 首页可以从“堆积”切入 |
| 7.5–15s | 通用的解读 | 三个不同的人收到同一份 AI 摘要，盖上「人人一样」 | 演示时可以先放一段通用 AI 的回应做对照 |
| 15–20s | 品牌 | 三块积木从三个方向拼合成图标 | 加载或空状态可以复用积木动效 |
| 20–30s | 内核 | 扫描线读原文，字段飞进事务卡，再展开成四步工作流 | 字段从原文“飞入”能直观体现可溯源 |
| 30–36s | 文件 × 你 | 屏幕分两半：同一份公司规章，求职学生和新员工各有一种解读 | 回应由“文件 × 人”决定，不预设分类 |
| 36–49s | 主动发现 · 可信复用 | 左边是记忆关联图，连线逐条点亮右边的 ✓△✗□ 清单，再盖「本次不能用」印章，最后点回原文第5条 | 连线把记忆和匹配项对应起来；✗ 用印章视觉，避免被随手勾掉 |
| 49–55s | 直接动手 | 日历标出截止，项目简介以打字方式生成（标「模型初稿」），导出 .md / .ics | 初稿标签和导出格式固定 |
| 55–62.5s | 按需索取 | 只问一句并说明原因，用户拍证书后，记忆图从4张卡长到22张 | 提问卡里写明“为什么问” |
| 62.5–69s | 同类产品 | 二维坐标：通用↔你的角度，停在回答↔推进到行动 | 文启的位置标为“目标位置 · 待赛中验证” |
| 69–76s | 团队版 | 五个工作块落下，五位成员的能力名片连到推荐块，用户访谈标为缺口 | 推荐附依据，不做监督 |
| 76–84s | 收尾海报 | 口号加巨字「文启」，然后淡出 | 可直接截帧作为 PPT 封面 |

## 3. 真实性边界

- 这是概念宣传片，不是产品录屏。界面、人物、通知、证书和数字（如未读129、记忆卡片22张）都是合成示意；画面角标一直显示「概念示意 · 合成数据」。
- 竞品坐标的位置是团队依据[[docs/02-调研与可行性/可行动事务Agent-竞品分析|竞品分析]]做的推断，不是评测结论；能力描述以该文档的来源为准。
- 这是赛前制作的材料，按赛事规则需要申报，不能当作本届实现成果。正式展示时要说明是“概念演示”，实际功能用赛中真实录屏展示。

## 4. 修改与重新生成

源码在 `src/`，依赖只有 Canvas 2D 和本机字体（Songti SC、PingFang SC），不需要第三方库。所有动画都只由时间 t 决定，可以逐帧复现。

| 文件 | 职责 |
|---|---|
| `core.js` | 画布、配色、缓动函数，以及文件、人物、印章、状态符号、品牌图标等绘图积木 |
| `scenes-a.js` / `scenes-b.js` / `main.js` | 场景1–4、5–8、9–11；`main.js` 还负责角标、百叶转场和渲染入口 |
| `music.py` | 配乐合成（需要 NumPy），各个重击时间点与场景切点对齐 |
| `capture.mjs` | 用无头 Chromium 逐帧取画布 |
| `build.sh` | 一键完成渲染、配乐和封装 |

```sh
cd docs/06-讲解视频/宣传片
open src/index.html                        # 实时播放（有 build/music.wav 时带声音）；加 ?t=秒数 可定格
node src/capture.mjs --preview 12.5,44,80  # 预览帧输出到 build/preview/
sh src/build.sh                            # 全量渲染约20秒，输出 output/文启-概念宣传片.mp4
```

渲染依赖本机的 Playwright 无头 Chromium（与旧讲解视频共用同一份 playwright-core，可用 `PW_CORE` 环境变量指定路径）、ffmpeg、Python 3 和 NumPy。`build/` 是中间产物，可以删除。调整场景时长时，要同时修改 `scene()` 的起止时间和 `music.py` 中的重击时间点。
