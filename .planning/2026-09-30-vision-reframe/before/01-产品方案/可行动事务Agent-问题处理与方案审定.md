# 可行动事务 Agent · 问题处理与方案审定

导航：[[可行动事务Agent-00-总览|文档总览]] · 分类：产品方案

> 本轮依据2026-09-26保存的市场与赛事来源，处理必须面对的问题；未重新联网核验价格或赛事更新。这里的“通过”仅指限定方案已形成一致、可检查的设计，不代表产品已运行、用户已认可或商业已经成立。

## 1. 本轮审定结论

**保留原始愿景，按“竞赛/项目报名材料复核与复用助手”进入限定原型阶段。** 先为一位正在准备报名的学生或项目负责人完成一件事，不要求建立完整知识库。

主线固定为：**通知先入 → 确认当前事务与适用分支 → 按需选择资料 → 逐项复核并导出 → 自愿保存可复用内容 → 新事务读取与重新检查。** 首次没有任何旧资料也能获得通知要求清单，但不能据此判定个人材料缺失。

本届冻结单用户、2份演示通知、每次最多5份选定资料、文本/PDF、来源查看、材料状态、可控持久记忆、过时处理及Markdown清单。团队协作、企业部署、后台提醒、自动提交、任意格式和完整资格判定退出本届范围。学时方案留档备选，不在开发途中同时做第二套产品。

若同题对照证明现有AI加模板已经同样方便，则优先将方法做成模板或插件，或停止独立应用投入。独立应用不是必须保住的结论。

## 2. 必须面对的问题及具体处理

| 编号与问题 | 本轮处理决定 | 怎么检查、失败怎么办 | 仍未消除的风险 |
|---|---|---|---|
| P01 现有工具已很强 | 做当前事务的要求—资料对照、变更与产物；不要求迁移网盘或知识库 | 与本人现有方法及合理提示的通用AI比较两次完整任务；无优势则转模板/插件 | 独立产品优势尚无实测证据 |
| P02 第一次没有记忆 | 先读通知，给要求清单；资料和保存均可跳过 | 零资料路径必须可用，个人项显示未检查 | 首次清单本身仍可能由通用AI很好完成 |
| P03 选资料仍有找文件成本 | 只选择当前事项有关文件；第二次复用自己曾保存的内容；保留原文件名 | 计入找文件、上传和确认时间；只省对照时间时据实宣传 | 首次不能承诺自动找到所有散落资料 |
| P04 人工确认吞掉效率 | 集中核对身份分支、强制材料、期限/渠道、禁用规则；普通选用与事实审核分开 | 记录逐项确认和纠正用时；清晰项不反复弹窗，未明项带原因与查证途径 | 必要确认不能靠减少按钮假装完成 |
| P05 找到就当可用 | 新增“不可用于本次”，按资料版本与要求配对判断；资格和材料状态分开 | 已确认禁用项不能由普通“选用”解除；换合法材料或核实规则 | 规则与事实审核仍可能出错 |
| P06 漏条款、漏附件或选错分支 | 显示已读取来源、未取得附件及覆盖范围；分开在校生/校友等分支 | 未读附件不能显示完整检查；身份不明先确认，明确不匹配则只作参考，不混合生成本人任务 | 首版不保证任意通知都能完整解析 |
| P07 旧版本、暂定时间被当真 | 同时保存原文、时间性质和版本；“暂定”跟随每次展示与导出 | 日期冲突保持未知；不自动选最早/最晚，更新后重新审阅影响项 | 没有接入权威更新源，不能保证实时最新 |
| P08 记错、停用后仍引用 | 已确认内容经选择才跨事务保存；修改/停用先令关联结果过时，再重新生成 | 新事务/刷新后读取；在途旧响应不得覆盖新版；停用不等于重新确认 | 关联范围只覆盖已记录依赖，不承诺全局推理撤销 |
| P09 隐私与删除说不清 | 单用户本机运行；未选择保存的工作副本仅留会话内存，原件不改；发云端的片段与服务方须说明 | 演示优先合成资料；真实试用先核对处理条件；删除来源同步清理派生片段、缓存及快照私密内容 | 本机存储不等于云模型不见数据，云端已接收内容和已导出副本不能靠本地删除撤回 |
| P10 模型调用与人工支持失控 | 通知和资料按版本缓存；集中匹配，技术失败最多一次自动重试；语义不明转待核实 | 记录调用、重试、耗时及人工分钟；超出样本范围提示缩减，禁止无限后台重跑 | 尚无真实成本和服务负载记录 |
| P11 67小时范围过大 | 一个事务类型、一个用户、三工作面；真实多人、文件打包和复杂条件全部后置 | 按第6节时间关口检查；核心不通则明确未完成，不能拿预填答案补成品 | 实际开发者技能和可用工时尚未确认 |
| P12 低频与收费缺证据 | 先观察活跃申请者，保留低频对照；按事务周期研究，暂不定长期订阅 | 同时报机会发生率、机会内复用和总成本；无复用/价值则收缩，不转企业逃避 | 尚无付费或可持续收入证据 |
| P13 团队/企业边界发散 | 社团先观察负责人个人工作；企业逐岗位另立问题假设 | 连续事务中现有表单确有缺口后再做协作；单独确认权限、付款人和集成成本 | 社团可触达不等于团队或企业市场成立 |
| P14 赛事外部条款未定 | 产品范围与赛事事实分离；评分、成果协议和提交入口列待确认清单 | 报名/签约前查看最终规则与完整协议，不自行解释矛盾 | 这些问题只能由主办方正式说明解决 |
| P15 准备好被说成报名完成 | 每项待办保留适用对象、阶段、渠道与依据；本届只交付准备清单 | 一个平台的回执只支持该渠道，不传播为另一平台已提交、审核通过或事项完成 | 无外部系统接入，不能核验对方实时状态 |

除P14仍依赖正式外部说明，其余问题均已落实设计处置，不能因此把风险登记成“已验证消失”。未代用户报名、接受协议或联系主办方。

## 3. 材料状态改成六种，并保留原因

判断单位是**某份资料的某个版本，对某项本次要求**。一份材料对甲事项不可用，对乙事项可能仍有引用价值；某份材料不合用，也不等于申请人整体没有资格。

| 展示状态 | 触发依据 | 下一步 |
|---|---|---|
| 未检查 | 用户尚未提供资料，或该项所需检查尚未完成 | 选择资料或继续检查；不写“你缺材料” |
| 可引用候选 | 来源可定位，本次已核对的适用检查没有发现冲突 | 由用户决定是否选用，保留已检查范围 |
| 需更新/确认 | 发现明确可补的事实、版本或形式问题 | 列出缺哪项事实、哪份新版本或本次签字 |
| 本次未找到 | 规则明确，选定范围非空且所需检查完成，在该范围未发现候选 | 显示检查范围，允许再补一份资料；不推断用户从未拥有 |
| 不可用于本次 | 已确认适用的禁止条件或排除事实命中该资料 | 排除该资料的本次选用；可更换材料或重新核实依据 |
| 无法判断 | 规则解释、适用分支、来源冲突或关键语义不明 | 给出待核实问题与对应来源，不强行归为缺失 |

同一项保留所有原因。资料已找到而“是否曾用于获奖”未知，属于需确认具体事实；禁止条款是否适用不明，属于无法判断；已证实命中适用禁用条款，属于不可用于本次。仅在输入证据或规则版本发生有效变化并重新审核后，才可重判禁用状态。

规则依据、事实证据、覆盖、审阅与选用分开记录。系统抽取候选不自动成为已审核事实；只有核对当前依据后的候选才能标为本人选用于草稿。已有候选可以展示，但其他文件尚未检查时仍保留部分覆盖；读取成功也不证明模型解释完整。

允许导出带“未检查/待核实/部分覆盖”的工作草稿，未审阅候选标为模型初稿。“需更新/确认”和“无法判断”留在待办区；禁用材料可列在排除说明中，均不能放入已选材料区。不使用“已全部符合”“完整资格通过”。准备、各渠道提交和审核分别陈述，不设自动“报名完成”终态。

## 4. 少量记忆也要有完整的生效与失效规则

最小关联链为：来源及版本 → 要求/个人事实 → 资料配对建议 → 事务结果快照 → 导出。个人意向另存，系统推测不自动写成事实。保存跨事务记忆时同时保留必要来源和用途，避免只留一个无法核验的摘要。

1. **当前事务**：未选择保存的文本、候选与快照仅留当前会话内存；刷新或退出可能丢失，提前说明，不落正文日志或磁盘缓存。
2. **选择保存**：用户选择已确认事实及必要来源文本，成功写入后才显示已保存；保留文件名、内容指纹和定位，首版不承诺保存PDF原件。未获准保存的片段不能借快照暗中留存。可拒绝保存并照常获取本次清单。
3. **新事务读取**：重新检查适用对象、版本、期限及禁用条件；历史确认不等于新任务自动确认。
4. **修改/停用**：增加版本与工作区失效标记，将关联结果、已审阅及选用标记置为过时；关联不确定时保守使当前草稿全部过时。重新生成后需复核，旧快照不作普通导出。重新打开或导出时也核对当前日期，防止过期材料仍被当有效。
5. **迟到响应**：服务端写入与页面接收分别校验任务版本、输入版本、失效标记和请求序号。删除或停用前启动的请求即使晚返回，也不能写回或显示私人内容；保存和导出再次校验。首版若不能保证多页同步失效，只允许一个活跃操作页面。
6. **清除**：应用控制范围内的保存文本、派生事实、缓存和快照私密片段按关联删除；仅留无正文的版本/删除标记防回填，不提供旧快照导出。外部下载文件带生成时间与版本说明，无法远程撤回；其他独立来源里的相同事实不宣称已被自动识别删除。

模型只提出要求与匹配候选；代码检查来源ID、引用片段、输入范围与版本，用户审核解释。通知或资料中的指令不改变系统权限；本届没有外部提交工具。服务仅本机可访问，密钥不进页面；真实材料试用前核对供应商处理政策，不能把单用户页面当权限系统。

演示至少覆盖一次重启/新事务持久读取、一次事实纠正或来源停用、一次旧结果过时。真实删除、隔离与并发行为仍需实现后检查；本轮没有运行软件来证明这些机制有效。

## 5. 重新审定的原型范围

| 类别 | 本届设计范围 |
|---|---|
| 用户与任务 | 一位学生或项目负责人；竞赛/项目报名材料复核，不做完整评奖或资格裁决 |
| 输入 | 每次一份主要通知及明确标识的关联来源；可跳过个人资料，选择时最多5份；文本/PDF |
| 演示样本 | 2份相关通知，2–5份合成或获授权脱敏资料；历史通知只作历史样本 |
| 三个工作面 | 通知要求、资料与依据、准备结果；记忆详情在侧栏查看 |
| 必做行为 | 通知先入、覆盖与分支、六种材料状态、来源回显、草稿导出、选择保存、新事务复用、纠正后过时 |
| 留存边界 | 本机单用户；当前事务工作副本与跨事务记忆分开，合成数据优先 |
| 不在本届做 | 文件打包、后台提醒、OCR泛化、全量采集、多用户权限、企业部署、学校接口、自动提交、复杂资格比较 |

通知附件不可取得时列为未读来源；PDF读取失败时明确请求粘贴文本，不把替代输入称为PDF解析成功。具体学校与通知尚未落实，实际开发前先选定可读且可解释的样本；样本超出能力时换样本或缩范围，并保留这个限制。

## 6. 交付关口与降级规则

67小时是官方总窗口，以下是团队内部安排，按一位熟悉所选工具的开发者估算，休息、活动、视频和提交均要占用时间；这不是已确认人力或交付保证。

| 关口 | 必须可见的结果 | 未达到时的处理 |
|---|---|---|
| 10月1日晚 | 选定样本与范围，开始通知→来源要求链；按真实进度完成团队介绍和基础资料 | 缩减文本长度与版式，不扩格式；首晚不要求完整产品 |
| 10月2日18:00 | 单次事务可操作：要求、选定资料、来源、状态和真实清单 | 取消装饰与可选细节，优先补核心；不能用固定答案替代 |
| 10月3日12:00 | 选择保存后，刷新/新事务能读取；一次变更使旧结果过时 | 将关联限制到显式来源，不做任意依赖推理 |
| 10月3日18:00 | 关键边界用例、第二次复用、完整5分钟展示可排练 | 冻结功能，只修阻断问题；未完成能力据实减少声明 |
| 10月3日晚至4日09:00 | 封存候选版本、运行说明与实际录屏，完成上传检查 | 预留传输和恢复时间，不临时切换另一套产品 |
| 10月4日09:30前 | 按最终入口完成有效封包并保存回执，备用录屏也已提交 | 不能靠下午展示时间或赛后修改补开发 |

实时抽取失败可展示错误及明确标识的人工审核输入，或使用封包前录屏；它们不能证明未实现的自动抽取。若持久记忆未完成，只能说完成单次材料整理，不能把同一对话上下文演成跨事务记忆。

5分钟建议：0–35秒问题；35–85秒通知先入与要求；85–145秒选择资料、复核与来源；145–205秒保存后新事务读取及一项禁用/需更新；205–255秒纠正、过时处理与实际清单；255–300秒AI分工、现场新增及边界。另有3分钟问答。分秒不是解析性能承诺，预审输入与回放须标明。

## 7. 审定分层，避免“设计解决”等于“市场验证”

| 层级 | 本轮状态 | 达到下一层需要什么 |
|---|---|---|
| A 设计审定 | **通过，限定为本篇范围** | 问题有具体处理、反例能得到一致预期、主线与边界没有明显冲突 |
| B 原型运行验收 | 未执行 | 实际输入、引用、导出、持久读取、禁用、过时及迟到响应均有运行记录 |
| C 用户价值验证 | 未执行 | 真实任务对照，包含找文件、初始化、确认、纠正、产物检查及第二次使用成本 |
| D 留存与商业验证 | 未执行 | 真实机会、复用行为、可持续成本和实际支付/采购证据 |

先访谈6名学生与2名社团负责人可以帮助找问题，但两组分开分析；活跃申请者与低频用户也分组记录。原“4/6独立完成、中位节时25%”只保留为可讨论的早期信号，不作为本次审定依据，更不自动触发扩大投入。

用户对照应包括本人最佳现有方法、合理使用的通用AI加模板，以及原型。采用难度接近的任务并交替顺序；两次任务既分开计时，也合计首次整理成本。人工救援记为辅助完成，保留全部失败分母；关键误导不能由速度抵消。另比较保存原文件与结构化记忆，证明新增维护是否值得。

在有真实第二次事务的人中计算再次使用，同时报告全部观察者的机会发生比例和发生次数；材料复用的分母是本次实际可复用项。失联/未知不能归为无机会，自然返回与被提醒后返回分列。无机会不直接记为流失，但机会很少会削弱收入空间；不按日活或月订阅假设经营。

成本表至少记录解析/模型、存储、重试、支付费用、人工审核/支持分钟和新增模板维护；创始人时间不能按零计，固定研发与获客另列。先按有限任务研究报价；口头愿付与真实付费分开。若替代更省事、关键错误未解决或人工成本过高，缩任务、改交付形态或停止独立产品投入。

| 反例 | 审定后的预期 | 记录 |

| 暂定截止、旧附件、学年冲突、历史通知 | 保留日期性质、未读附件及冲突；只影响相关项，不凭常识补期限 | S04–S05、S08 |

| 零资料、部分读取失败、查完无候选 | 分别为未检查、未检查并标部分覆盖、限定范围内本次未找到 | T01–T02 |
| 旧名单、旧签字、计划数字 | 具体事实需更新；不能生成本次签字或将计划变成已发生 | S03、S07、S09、T04–T06 |
| 纠正后旧响应迟到；停用/删除时保存仍在途 | 版本不匹配即拒绝；旧选用失效，被删正文不能复活 | T08–T09 |
| 拒绝保存；选择保存后重启新事务 | 前者仍可导出本次草稿；后者仅读取已获准保存内容并重审 | T10–T11 |
| 首晚上传与最终封包、已有更好工具 | 按阶段与有效回执判断；允许结论为使用现有工具 | S10–S12 |
