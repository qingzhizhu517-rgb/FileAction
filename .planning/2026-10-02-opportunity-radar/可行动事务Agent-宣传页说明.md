# 可行动事务 Agent · 文启宣传页

导航：[[可行动事务Agent-00-总览|文档总览]] · [[01-产品方案/可行动事务Agent-参赛主线方案|参赛主线方案]]

## 打开页面

直接用浏览器打开本目录的 `index.html`，无需安装依赖或构建，也可以从仓库根目录启动：

```sh
python3 -m http.server 8787 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8787/07-宣传页/
```

## 页面内容与交互

- 暖黄色品牌首屏、大标题与七份错落排列的文件，手机端精简为五份；低对比文字背景随鼠标轻微偏移，标题区域保留留白。
- 第二屏展示十二份杂乱散落的合成文件，随着继续下滑逐渐转正、移动并归位成整齐阵列。
- 主动发现、可信复用、直接行动三项产品价值。
- 竞赛通知、奖学金申请、实习简章三个可切换的合成场景；支持键盘左右方向键、Home、End。
- 查看各场景判断依据，导出包含材料对照、待办与依据的 Markdown 示例清单。
- 按需了解用户、个人记忆设计、团队版规划、常见问题。
- 底部入口跳转到已有的文启高保真交互 Demo。
- 桌面、平板与手机自适应；移动端导航、滚动渐入、减少动态效果偏好支持。
- 动态文字层在指针停止、首屏离开视口或标签页隐藏后停止绘制；减少动态效果偏好下保持静态背景，触屏不跟随指针。

## 动效增强

- 首屏标题分段入场、下划线描绘、文件阵列登场与轻微鼠标倾斜；保留上浮粒子、暖黄流动光晕与文件错相浮动。
- 首屏文件依次展示竞赛通知、项目介绍、获奖证书、想法、实习简章、个人简历和行动清单。可以打开合成预览，不接收真实上传。
- 向下滚动时首屏短暂吸附，文件按从左到右的次序、自下而上擦除，边缘带金色光线；下方页面从底部上推覆盖首屏。向上滚动可还原，不接管滚轮或自动跳页。
- 短屏先自然滚动至文件完整可见再进入擦除段；系统减少动态效果或禁用 JavaScript 时，文件保持静态、页面按普通文档流浏览。
- 功能卡片随滚动由轻微折叠状态逐层展开，配合错峰入场、鼠标倾斜与聚光；卡片内文档摆动、材料行轮流亮起、待办图标弹动。
- 按钮磁吸位移、悬停扫光、点击粒子；导航底部显示阅读进度。
- 切换场景时，文件扫描光带与结果逐条入场；只表现预设示例切换，不代表真实解析进度。
- 记忆星图的关联曲线带流动光点，团队卡片轮流亮起，底部旋转光环及 FAQ / 弹窗入场。
- 右下角可暂停或恢复装饰动效；系统减少动态效果偏好下关闭新增动态效果。离屏区块、隐藏标签页暂停循环动画，手机减少粒子数量。

## 直接操作的动画

- **点开文件**：悬停时文件抬起并扫光，点击后从原位置放大为预览，关闭时收回。预览中可用前后按钮或左右方向键翻阅七份示例；“探索这个场景”联动下方对应演示。Escape 关闭并返回原文件焦点。
- **聚拢 / 展开**：文件阵列可收拢成居中的一叠，再展开回原位。继续向下滚动会自动展开，接回原来的擦除转场；文件擦除时不再参与鼠标与键盘交互。
- **记忆星图**：点击节点查看对应的合成关联说明；拖动节点时曲线实时重连。点击中心点亮全部路径，“重置星图”使节点和连线一起归位。支持鼠标和触摸拖动，聚焦节点后可用方向键移动，Shift 加方向键加大步长。
- **场景滑块**：选中背景跟随场景按钮滑动，保持原有键盘切换、扫描光带和结果入场。
- 暂停或减少动态效果时，预览、切换、节点操作仍可用，装饰性变形和循环动画停止。没有 JavaScript 时显示静态文件与星图，文件按钮不生成，星图控件保持禁用。
- 文件内容、星图节点和关联均为预设示例；拖动位置仅留在当前页面内存中，刷新后重置，不会建立或保存真实个人记忆。

## 第二屏：从散落到有序

- 位置紧接首屏，在产品价值区之前。首屏底部“向下滚动，开启下一页”入口跳转至此。
- 十二份文件以不同位置、倾角、叠放次序散落在画板上，初始卡片只显示文件标题。继续下滑时，画面短暂吸附，文件按错开的进度转正并移动归位，对齐参考线与进度条同步显现。
- 标题逐渐上移，标题下方的具体解读按各文件自身的归位进度分三层出现：与你的关联或可复用内容 → 判断依据或待核实事项 → 建议下一步。文字以淡入、轻微上移和逐行揭示呈现，不使用假文字横线代替解读。
- 文案分别体现主动发现、可信复用、直接行动。例如“项目介绍”依次显示“项目背景可复用”“已确认版本 v2”“起草参赛简介”；“获奖证书”提示本次认定范围待核，“申请草稿”保留模型初稿待确认的状态。
- 桌面为六列两行，平板为四列三行，手机为三列四行；十二份文件始终保留。短屏先自然滚动至画板完整可见的位置，再进入整理段。
- 动画进度直接对应滚动距离，不接管滚轮或自动播放。向上滚动时文字按相反顺序收起，最终回到只显示标题的散落构图；归位后继续下滑进入产品价值区。
- 暂停动效时冻结当前构图和文字显现进度，恢复后同步当前滚动位置。系统减少动态效果或禁用 JavaScript 时直接显示整齐阵列及完整解读，按普通文档流浏览。
- 文件、解读和整理计数均为预设合成示意，不代表真实文件解析、分类或处理进度；画面明示“预设合成解读 · 未接入模型”。
