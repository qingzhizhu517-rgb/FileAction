# 可行动事务 Agent · 可行性分析

导航：[[可行动事务Agent-00-总览|文档总览]] · 分类：调研与可行性

> 本轮沿用2026-09-26读取的市场与赛事证据，未重新联网核验。处理决定以 [[01-产品方案/可行动事务Agent-问题处理与方案审定|可行动事务Agent-问题处理与方案审定]] 为准；产品方案见 [[01-产品方案/可行动事务Agent-Idea完善方案|可行动事务Agent-Idea完善方案]]。本篇判断设计是否值得进入限定原型，不能代替运行或市场验证。

## 一、当前判断与审定层级

**竞赛/项目报名材料复核与复用助手，可以按限定设计进入原型阶段；独立产品和商业模式尚未成立。** 通知要求、资料来源、适用限制和下一步集中展示，可能减少人工对照，但现有AI加模板也可能同样方便。

| 层级 | 当前状态 | 通过所需证据 |
|---|---|---|
| 设计审定 | 限定范围通过 | 问题有处理、反例有一致预期、流程与边界协调 |
| 原型运行 | 未执行验收 | 真实输入、六状态、引用、导出、持久读取、禁用、过时和迟到响应的运行记录 |
| 用户价值 | 未执行验证 | 与最佳已有方法公平对照，计入全部输入、确认与纠错成本 |
| 留存与商业 | 未执行验证 | 真实第二次机会、复用行为、实际支付及完整成本 |

可接触学生和社团是验证渠道，不是需求或付费证明。公开通知证明流程存在，竞品证明相关能力已有供给；若同题没有优势，应转为模板/插件，或停止独立应用投入。

## 二、关键问题与具体处理

| 问题 | 当前处理 | 验收与失败调整 |
|---|---|---|
| 首次没有记忆 | 通知先入，先给要求清单；资料可跳过，留存可拒绝 | 零资料路径可用且显示未检查；首轮无价值就缩任务，不强迫建档 |
| 找文件与确认成本 | 只选本次相关资料，集中核对分支、强制材料、期限/渠道和禁用条件 | 计入寻找、选择和纠正时间；不把少建档宣传成首次自动找齐文件 |
| 文件存在但不适用 | 按资料版本与本次要求配对，保留原因与覆盖范围 | 禁用项不能由普通选用解除；缺附件、分支不明时不称完整检查 |
| 记忆过期或纠正失效 | 自愿保存来源与用途；改动先使直接关联结果过时，再重新生成 | 刷新/新事务真实读取；迟到旧响应不能覆盖新版或激活停用来源 |
| 支持与调用失控 | 按版本缓存、集中匹配；技术失败最多一次自动重试，语义不明转待核实 | 记录调用及人工分钟；超范围缩输入，不用无限重试或后台人工补齐 |
| 协作与企业扩张 | 本届只观察负责人个人工作，团队/企业另立假设 | 现有表单无明确缺口、付款人和接入条件未落实时，不扩产品 |

可追溯仍可能误读；结构正确也不代表事实正确。输入文件是待处理资料，不是系统指令。只记录显式关联，不承诺任意知识图谱推理或全局撤销。

## 三、六种材料状态与输出边界

状态作用于“某份资料的某个版本，对本次某项要求”，不判断申请人整体资格。

| 状态 | 判定边界 |
|---|---|
| 未检查 | 未提供资料或所需检查未完成，不能判个人缺材料 |
| 可引用候选 | 来源可定位，已完成的适用检查未发现冲突，仍展示检查范围 |
| 需更新/确认 | 有具体可补的事实、版本或形式问题，写清需要谁确认什么 |
| 本次未找到 | 规则明确、选定范围非空且检查完成，范围内未发现候选；不推断从未拥有 |
| 不可用于本次 | 已确认适用的禁止条件或排除事实命中；排除本次选用 |
| 无法判断 | 规则、分支、来源冲突或关键语义不明，列出问题与来源 |

一项可保留多个原因。事实审核与选择使用分开；禁用状态须有有效证据/规则变化并重新审核才能重判。可导出带未检查、待核实和部分覆盖标记的Markdown工作草稿；禁用材料仅列排除说明。导出不等于材料齐全、资格通过或已提交。

## 四、本届范围与降级

固定单用户、2份演示通知、每次最多5份选定资料、文本/PDF。三工作面为通知要求、资料与依据、准备结果。主链为：**通知先入→确认事务与分支→按需选资料→复核并导出→自愿保存→新事务读取并重新检查**。

本届做来源查看、六状态、可控持久记忆、纠正后的过时处理与Markdown清单。文件打包、后台提醒、OCR泛化、全量采集、多用户权限、企业部署、学校接口、自动提交和完整资格判定均退出本届。学时规格留档备选，不作为主线契约，也不在开发中途另开第二套产品。

解析不稳定先缩版式和输入；未取得附件要保留覆盖缺口。人工审核输入和封包前录屏可以作为明示的降级，不能证明自动抽取已经实现。持久读取未完成只能称单次材料整理；核心未通须据实声明，不用固定答案填成成品。

## 五、用户对照与低频观察

主实验聚焦近期有竞赛/项目任务的学生，保留低频用户和已有满意工具者作反证；社团负责人单列。6名学生、2名负责人是探索建议，不具代表性；原4/6独立完成和中位节时25%仅为可讨论的早期信号，不是本次设计通过或扩大投入的依据。

对照包括本人最佳已有方法、合理使用的通用AI加模板及原型。提供相当的通知、附件、旧资料与确认机会，采用难度接近的任务并交替顺序。找文件、上传、初始化、确认、纠正、产物检查和导出全部计时，首轮、第二轮和两次合计分别报告；同时看绝对分钟和错误，不只看模型速度。

所有开始任务的人都保留在完成/失败分母中。研究者代选材料、解释规则或改输出，单列辅助完成并记录时间；不能删除困难样本或用辅助结果证明自助能力。

预先固定观察窗口，同时报告第二次机会发生率、有机会者中的自然返回/复用、全体首用者的再次使用和实际复用项。无机会、未知/失联、提醒后使用分开；未知不能当无机会。重放历史通知不是留存；机会稀少虽不直接等于流失，也会削弱收入空间。

## 六、成本、数据与收费退路

完整记录模型/解析、存储、技术重试、人工审核、支持和模板维护成本，创始人工时不按零计。用户必要确认与服务方额外代办分别记录；既看中位数，也看最耗时失败。单次贡献需扣除可归属成本，固定研发和获客另列，不能只用API费用推导盈利。

先研究可限定范围的按次或任务包交付，报价选择、口头愿付和真实支付分别记录。有同一付款人的重复任务与购买后，再考虑学期方案；不预设月订阅或个人免费自然转企业。省事但不付费可退回模板/轻量工具；愿付但人工过重，则收缩范围或明确成为服务，不冒充已可规模化的软件。

设计采用本机单用户工作目录，原件不改；当前事务副本与跨事务留存分开。真实试用前说明输入用途、模型服务方、发送片段与清理方式；本机保存不等于云模型不见数据。清除须处理派生索引与缓存，已导出副本无法远程收回；这些机制仍待实现验收。
