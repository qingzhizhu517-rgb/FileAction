核心强调：

目前模型能力，知识含量都已经很强了，之后可能更强。也就是知道的多。如果它不了解你，那这个可能就是缺点，所以项目核心沉淀，供给它 高质量输入

无痛化输入，将各种文件，pdf，你的个人定位进行一次沉淀

路演答辩针对学校场景一个 demo，公司场景一个 demo


### 示例：上传《2026 年国家奖学金评定办法》

**普通 AI 的输出**：该通知主要包括以下几点……

**本方案的输出**：
```
发现一项可行动事务

【国家奖学金申请】
类型：Opportunity
截止：10 月 XX 日
提交对象：XX 老师
适用对象：本科生（条件判定见证据链）

要求：
  ✓ 成绩排名      来源：《评定办法》第 3 条
  ✓ 综合测评      来源：《评定办法》第 3 条
  ✓ 获奖经历      来源：我的《XX 比赛获奖证书》
  □ 个人事迹材料   来源：—
  □ 申请表        来源：学校模板
  □ 指导老师确认   来源：—

下一步：「整理我的材料包」
```
- **校园场景拥有高度标准化、强规则、强时间节点、强材料要求的文档体系，是验证「Document → 可行动事务 → Workflow」这一能力的天然实验场。**

这些文件天然具备：对象 / 条件 / 时间 / 材料 / 流程 / 责任人 / 例外情况——**是规则化推理最理想的训练与验证环境**。

团队版
理想化：每个人都在用本项目，并且沉淀出了个人信息。而团队版是汇集 agent，针对每个人进行输出，团队成员也都对汇集 agent 白盒展示。

企业版
**企业侧入口不是「企业 AI 知识库」**（Glean / Notion / 飞书 / M365 已极强），而是：

> 凡是「收到一份文件/通知 → 判断谁需要做什么 → 准备材料 → 执行 → 汇报」的流程，都是市场。

例如教育机构：教育局通知 → AI 理解 → 判断涉及哪些教师 → 生成任务 → 匹配模板 → 教师提交 → 自动汇总 → 负责人周报。
