## 3. 原始产品 DOCX：接近，但仍有差别

原始 V1.0 并非完全相反：它已经明确“长期记忆和旧材料复用是辅助机制，不是产品中心”，并允许用户选择、暂停或拒绝。这些与本次方向一致。仍需避免直接沿用的表述包括：

- 第1.1节“行动是主要交付”：本次以个性化解读为首个完整交付，行动由用户后续选择。
- 第2.2节“首版必须做深活动通知这一条主链”：可作为实现选样参考，不能覆盖新原稿的非单一通知边界。
- 第3.2节“同时将此次上传的文件和上下文沉淀为个人记忆”：需补上用户查看、修改和决定是否保留的选择。

该 DOCX 已被标为原始参考输入，本次不直接改写二进制原稿；以上差异在现行主线落实，导航继续明确其非现行口径地位。
