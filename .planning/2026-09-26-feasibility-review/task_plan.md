# 项目文档与可行性全面核查

## 范围
审查全部现行项目文档、历史草稿和 AGENTS.md，修订现行正文；不修改个人编辑器状态。

## 阶段
1. [已完成] 核查内部一致性、技术契约和可行性假设。
2. [已完成] 核实关键外部论据，明确证据与未知。
3. [已完成] 统一方案边界并修订各文档。
4. [已完成] 检查链接、示例数据、状态、格式及残留矛盾。
5. [已完成] 完成交付报告与可行性结论。

## 决策
- 现有目录无应用代码或 Git 历史，能力及指标一律按拟实现/待验证表述。
- 不用文档宣称代替实测；优先缩小 MVP 和定义验收。

## 工具问题
- 首次豆包搜索缺少凭证；改用可用的公共检索或官网直读，不索取密钥。

- 定位决策首次整篇替换因补丁工具不支持同一路径删除再添加而拒绝，未修改文件；改为读取原文后整段更新成功。
