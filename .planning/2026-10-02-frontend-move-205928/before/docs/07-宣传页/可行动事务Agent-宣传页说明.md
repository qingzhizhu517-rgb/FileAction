| 页面与动效 | 对应路演功能亮点 | 观众可以做什么 |
|---|---|---|
| 首屏：文件阵列聚拢、预览与擦除接页 | 文件是入口；收到文件，先交给文启 | 预览示例，进入对应阅读场景 |
| 第二屏：十二类常用文件归位，四类重点逐渐突出 | 从日常通知与方案中理解值得关注的内容 | 滚动看重点与解读渐显，回滚还原 |
| 第三屏：文件扫描、背景连接与关联判断展开 | 解释为什么与你有关；区分原文、背景与未知 | 切换学生、教师、业务负责人示例，展开依据 |

| 收尾：愿景入场与预设体验入口 | 个人端 MVP 验证；未来探索团队与企业级应用 | 进入已有独立交互设计稿 |

- 沿用暖黄配色、首屏七份文件（手机五份）和整体留白；导航为“阅读重点／与你有关／继续行动／预设体验”。
- 三种身份是路演中的举例，不是产品的身份或文件分类边界。
- 原“材料核验台”由理解到行动的功能展示替代；原文回溯移到第三屏关联判断中。
- 桌面、平板、手机自适应，保留移动导航、全局暂停和减少动态效果支持。

## 动效增强

- 首屏标题分段入场、下划线描绘、文件阵列登场与轻微鼠标倾斜；保留上浮粒子、暖黄流动光晕与文件错相浮动。
- 首屏文件依次展示奖学金通知、项目经历、申报指南、与你有关、合作方案、本次积累与可编辑产物。预览说明与后续入口同步对齐路演。
- 向下滚动时首屏短暂吸附，文件按从左到右的次序、自下而上擦除，边缘带金色光线；下方页面从底部上推覆盖首屏。向上滚动可还原，不接管滚轮或自动跳页。
- 短屏先自然滚动至文件完整可见再进入擦除段；系统减少动态效果或禁用 JavaScript 时，文件保持静态、页面按普通文档流浏览。
- 按钮磁吸位移、悬停扫光、点击粒子；导航底部显示阅读进度。
- 第二屏阅读重点随滚动浮现；第三屏个性化解读、第四屏理解传递至产物说明均在画板进入视口后自动播放。动画是预设呈现，不代表文件解析或模型生成进度。
- 保留底部旋转光环、收尾内容入场及文件预览和原文弹窗。
- 右下角可暂停或恢复装饰动效；系统减少动态效果偏好下关闭新增动态效果。离屏区块、隐藏标签页暂停循环动画，手机减少粒子数量。

## 直接操作的动画

- **点开文件**：悬停抬起、点击放大预览、关闭收回；前后按钮或左右方向键翻阅。预览可进入对应的个性化解读；最后一份进入行动功能展示。Escape 关闭并返回原文件焦点。
- **聚拢 / 展开**：文件阵列可收拢成居中的一叠，再展开回原位。继续向下滚动会自动展开，接回原来的擦除转场；文件擦除时不再参与鼠标与键盘交互。
- **解读与依据**：三场景切换支持左右方向键、Home、End；依据弹窗支持原文高亮、可选补充、修改笔记与自主保留。
- **理解到行动**：直接自动展示已确认信息如何承接到具体产物，取消第四屏选择控件、示例操作区与下载。
- 暂停或减少动态效果时，预览、场景切换、依据和编辑仍可用；没有 JavaScript 时显示静态内容，第三屏提供奖学金依据折叠区。
- 所有材料与判断均为预设合成示例；补充和保留状态仅在当前页面内存中使用，刷新清除，不建立真实长期记忆。

## 第二屏：从逐段筛选到阅读重点

- 按用户确认的方案展示十二类常用文件：放假通知、会议通知、考试安排、招聘通知、培训通知、奖学金申请通知、活动策划方案、项目实施方案、合作方案、工作计划、宣传推广方案、项目预算表。
- “招聘通知／奖学金申请通知／项目实施方案／合作方案”四类保持强调；其余文件逐渐淡化但仍保留。四类是展示重点，不代表某位用户的真实匹配结果，也不是产品固定分类。
- 初始只有文件标题；随滚动逐层出现阅读重点、与个人背景或当前工作的联系、待核实事项。例如招聘通知提示对照求职意向，奖学金通知联系调研经历，实施与合作方案关注任务、资源和交付。
- 桌面六列两行、平板四列三行、手机三列四行；长标题可换行，手机卡片为双行标题预留高度。短屏先自然滚到画板再吸附。保持原生滚动与反向还原，不强制跳页。
- 全局暂停冻结进度；减少动态效果或禁用 JavaScript 时显示完整静态解读。所有内容和计数为合成示意，不表示真实解析结果。
- 常用文件替换后已在 Chrome 检查 `1440×900`、`1024×768`、`768×1024`、`390×844`、`320×568`：十二个标题与三十六条解读完整，四类强调正确，滚动渐显、回滚和静态回退正常。截图与脚本位于 `.planning/2026-10-02-common-files/`。

## 第三屏：解释为什么与你有关

- 标题为“不只说文件写了什么，更解释为什么与你有关。”画板进入视口自动播放约 5.2 秒：文件进入、扫描要求、连接四类理解线索，再展开个性化解读。
- 四个节点分别为文件明确写的、本人确认的背景、还不能确定的、当下想了解的。桌面并排显示关联图与结果，移动端在同一舞台交接。
- 学生示例：奖学金通知联系已完成的校园调研；综测排名和成果认定待核实。教师示例：申报指南联系学习支持研究；资格、限项、成果条件待核实。业务负责人示例：合作方案联系当前调研需求；交付、验收、资源安排待确认。
- 切换或重播场景时更新第三屏解读与依据。动效按时间推进，不需要继续滚动；完成后保留结果。离屏、后台、全局暂停、打开依据弹窗时冻结，恢复后续播。
- 全局暂停时主动切换场景，直接呈现新解读，仍可展开依据。
- 点击“展开依据与相关背景”并排查看合成原文与确认背景，原文重点高亮；另列关联判断与未知，避免把推断写成原文事实。
- 弹窗根据当前场景只问一个影响判断的问题，可补充，也可暂时跳过；确认的补充记录在本页会话中，默认笔记随交流更新，已编辑的笔记不被覆盖。
- 本次笔记从示例文件及交流形成；可以修改、保留当前版本或移除。修改后须再次保留才会更新保留版本，保留仅在本页会话中生效。
- 弹窗支持键盘焦点循环、Escape、关闭按钮与遮罩关闭。所有自填文本按纯文本处理。
- 本屏不吸附、不增加长滚动占位。减少动态效果显示关联图及完整结果；无 JavaScript 显示静态奖学金示例和依据折叠区。

## 第四屏：直接展示从理解到行动

- 标题为“读懂之后，继续帮你往下做。”保留暖黄双栏构图，左侧说明承接原文要求、确认背景与本次交流，右侧说明具体产物及信息沿用、内容可改、本人确认三个要点。
- 进入视口自动播放约 3 秒：理解内容出现、连接线传递、产物说明与三个要点依次展开。无需继续下滑或点击。
- 已删除场景下拉框、“只想了解／继续”选项、下方示例编辑区、产物切换、下载和重播按钮；第四屏不再保存示例产物状态。
- 用户自主决定作为简短说明保留，不做交互选项。动画为功能概念展示，不代表实际生成或对外发送。
- 离屏、后台、全局暂停或依据弹窗开启时冻结，恢复后续播；减少动态效果和无 JavaScript 时完整静态呈现。
- 桌面双栏、手机纵向排列；第四屏后直接接收尾栏和页脚，既有导航锚点继续有效。
