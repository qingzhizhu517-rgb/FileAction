## 1. 一句话

**文启是一个以文件为入口的个人行动助手，帮你理解一份文件对当下的你意味着什么，再把这份意义变成具体行动。**

口号：**收到文件，先交给文启。** 用户首先想知道的是：“这份文件对我意味着什么？”

核心痛点是收到文件后，反复通读、筛选，再把内容与自己联系起来；下一份文件到来时，又要重新介绍相关背景。首个交付应是有依据的个性化解读：哪些内容与我有关、为什么值得关注、有什么要求或限制、哪些问题还不能确定。用户仅想了解或判断暂时无关时，这份解读本身就是完整交付。

材料复用、缺项清单和起草是特定场景里的支持能力；记忆是理解的基础。它们都不取代“文件对当下的我意味着什么”这一核心。

产品名为文启 / FileAction，2026年10月1日确定，取代“旁批 / Margin”。名称尚未完成商标核查；旧视频和设计稿保留各自制作时的名称与视觉，不作为当前产品完成状态的证明。

## 2. 内核：先理解意义，再由用户选择是否行动

```text
收到文件 → 理解内容、要求与限制 → 结合本次提供或已确认的相关背景
  → 解释哪些内容与我有关、为什么，以及尚不确定的部分
  → 用户选择：到此结束 / 补充或纠正 / 继续行动
  → 选择行动后，形成可编辑的具体产物
```

Document → 可行动事务 → Workflow 保留为可选行动路径的内部表达，不要求每份文件都生成事务卡或工作流。文件与人的关系决定回应，不预设固定文件分类，不强迫进入材料核对或任务流程。

每条影响用户判断的解读应区分：**文件明确写的内容、结合的个人背景、系统推断、尚不确定的部分**。关键判断能回到实际可定位的原文和背景来源；“可能适合”不等于符合资格或已决定参与。缺背景、附件或规则不清时明确标注，不补造事实。

### AI 与确定性代码的分工

| 环节 | 作用与约束 |
|---|---|
| 文件解析与模型理解 | 识别非结构化内容、要求、限制和语义关系；只承诺实测支持的格式，读不清时提示 |
| 个性化解读 | 结合相关背景解释关联理由，区分原文、背景、推断与未知，允许纠正 |
| 可选产物生成 | 沿用户选择的方向起草，用已确认的信息，不编造经历，初稿可编辑 |
| 确定性代码 | 管理来源定位、保存和删除、版本失效、授权及对外操作确认，不依赖模型自行遵守权限和状态规则 |

规则可以处理已定义的校验，模型承担开放文件与个人背景之间的语义理解；不宣称“规则完全做不了”或“通用 AI 只能总结”。模型失败时应明确报错，不能用预置答案冒充新文件理解。

## 3. 个人版：个性化解读是第一交付

### 文件入口与开放回应

以文件为入口，用对话、原文引用和按需出现的组件解释内容。页面形式服务于理解，不预设每次都必须展示的材料三态、能力名片、关联图或固定步骤。

例如，用户已确认正在寻找教育方向实习，上传公司介绍后，可以指出与该方向有关的信息和需要进一步核实的条件。若文件没有岗位或招聘信息，应明确缺少依据，不能把相关性补写成招聘事实。

### 信息不足时才询问，可以跳过

首次使用不要求填个人资料表。先展示有依据的内容和判断边界；只有缺失信息会影响判断时，才说明原因并适当询问。问题数量由实际需要决定，不固定“先问一个问题、点击后必有第二版”。用户暂不补充，仍能获得当前证据支持的解读；未知部分保持未知，不把猜测当作已确认身份。

### 沉淀逐步形成，用户决定是否保留

沉淀来自本次文件和实际交流，不按预设个人档案模板强行收集。系统展示拟沉淀的内容与来源，供用户查看、修改并决定是否保留。

**确认信息属实、用于本次理解、保存供以后使用，是不同的选择。** 回答问题或纠正判断不等于同意长期保存；不保存也应能完成本次解读和已选择的行动。已保留内容可查看、修改、停用或删除，重新使用时核对是否仍适用于当下。事实或来源改变后，受影响的旧结果需重新核对；已下载或发送的外部副本不会自动更新。

### 理解后，由用户决定是否继续

用户可以在“我知道这份文件对我意味着什么”处结束。选择继续后，再生成申请陈述草稿、需要核实的问题、材料清单或合作讨论提纲等可编辑产物。沿用已确认的信息，避免重复解释；未确认的信息作为待补项。重要决定和对外发送由用户确认，不承诺自动提交、代签字或代替用户判断资格。

### 材料复用是场景能力

奖学金或申报场景需要时，可以对照材料与本次要求，解释可引用依据、更新需求和限制。仅在适用条款与触发事实都有依据时，才提出“本次不适用”；过去使用过不自动等于本次禁止使用，规则不明时保持待核实。材料状态不成为所有文件的固定分类；准备清单不等于已报名，材料齐全不等于资格通过。

## 5. 企业版：未来探索

业务负责人以个人身份阅读合作方案，是个人端的一个场景：结合当前项目，理解值得关注的内容和需要向对方确认的问题。这不等于企业部署、多人权限、审批或组织级数据能力。企业级应用的使用岗位、授权机制、组织集成、付款人和收益均待独立验证，本届不承诺企业 Demo。

## 6. 本届范围与验收

**当前仓库状态（2026年10月3日）**：根目录已新增 `src/`、`tests/` 与本机启动入口；合成替身流程通过验收，`gpt-5.6-sol` 真实模型的合成材料流程已验收，真实 COS 待配置后验证。下表仍是完整产品目标，不是逐项完成清单，实际实现范围以运行与验收记录为准。

| 优先验证 | 验收重点 |
|---|---|
| 文件输入、解析和真实模型理解 | 公布实际支持格式；失败、缺页和无法定位的内容如实提示 |
| 结合背景的个性化解读 | 解释关联内容、原因、要求与限制；没有个人档案也能开始 |
| 证据与未知分开 | 关键判断可回到原文与背景；推断、待确认事项可识别 |
| 按需询问与纠正 | 问题有必要性说明，可跳过；纠正会影响相关解读 |
| 本次沉淀展示及保留选择 | 可查看、修改、保留或不保留；回答问题不默认授权保存 |
| 用户选择后的可编辑产物 | 用上已确认信息，不重复索取；允许只理解、不继续行动 |
| 合成体验与试用入口 | 样例、人设明确标注，可重置；预设体验不等于预填分析答案 |

不作为当前必交付项：团队分工推荐、能力名片、企业部署、后台推送、日历导出、关系图可视化、自动提交、全量采集聊天或邮箱。是否后续加入，服从个人端验证结果和真实实现进度。

学生奖学金、教师申报、业务负责人合作方案用来说明同一方法面向不同的人。奖学金可作为首个合成体验，不是唯一文件种类或目标人群；不为展示而承诺三套已实现的专用流程。

### 评委试用目标

- 同一合成文件可以配合不同的已确认背景，对比阅读重点与依据；有背景和无背景均可尝试。
- 能跳过问题、纠正背景、选择不保存或不继续行动，不被强制进入固定流程。
- 选择行动后能编辑产物，并看到它使用了哪些已确认信息。
- 读不出、模型超时或依据不足时明确提示，不静默切换成演示答案。
- 如实现公网服务，按实际部署落实测试账号、合成样例、重置、服务端密钥、调用额度与模型外发说明，不鼓励上传真实敏感资料。

## 10. 验证信号与路线图假设

| 层级 | 待验证问题 | 行为证据 |
|---|---|---|
| 个人端，当前主线 | 是否更容易知道文件对自己的意义 | 能说明关联理由并核对依据；阅读、补充、纠正耗时；第二份文件实际复用背景 |
| 可选行动，个人端延伸 | 已理解的信息能否直接用于推进 | 用户主动选择继续、编辑或导出；同时记录只理解后结束 |
| 团队协作，未来 | 是否有值得独立解决的协作需求 | 后续真实队伍的使用行为，当前不填接受率或虚构案例 |
| 企业级，未来 | 是否有岗位价值和付款意愿 | 后续明确岗位、授权范围和实际试点，当前不推定 |

仅上传文件、提供截图或口头愿意使用，不足以证明核心价值、习惯或付费需求。选择不行动不自动算失败，关键是是否完成理解目的。

## 11. 商业需求与用户验证

首批观察近期确实收到需要判断相关性的文件的人。学生可以是便利样本，不要求“多次参赛且临时组过队”，不定义为唯一人群。教师与业务负责人场景各自验证，不能将学生样本外推给其他人群。

优先验证：收到文件后具体读了什么、筛掉什么、联系哪些背景；解读是否指出有关内容及理由；补充与纠正成本；能否跳过或不保存；是否实际使用解读或产物，以及下一份文件能否减少重复解释。材料复用仅在适用样例中检验，团队分工不是本轮主线。

个人按次或订阅、未来机构采购均为待验证假设，当前没有付费证据。不预设学生付费意愿弱，不默认学院或机构会购买。先记录理解阶段的阅读、补充、回读和纠错总耗时，再单独记录可选行动阶段；回忆估计、真实计时与合成场景测量必须分开，不能直接相减后宣称已证明节省。

同题比较应给各工具同一份文件、相同的已确认背景和相同目标，记录模型版本、日期及全部交互成本。只让对照工具总结、却给文启更多背景，不是公平比较。未核实的退回风险或机会损失，不折算成收益或 ROI。

执行方法见[[docs/03-参赛与路演/可行动事务Agent-用户验证执行卡|用户验证执行卡]]；竞品来源与未核实项见[[docs/02-调研与可行性/可行动事务Agent-竞品分析|竞品分析]]。本次仅调整内部分析重点，不更新外部来源读取日期。

## 12. 不变的底线

- 合成资料与设计示意明确标注，不编造用户、经历、访谈、完成状态或测试结果。
- 区分原文、用户背景、推断与未知；模型初稿不等于用户确认。
- 补充自愿、保存另行选择；不要求先建档，不强制行动。
- 说明哪些片段发给哪个模型服务，本机保存不等于云端模型看不到数据。
- 重要决定和对外发送由用户确认，准备清单不等于报名或资格通过。
- 团队与企业留在未来探索，不能写成本届已完成能力。
- 不使用“零幻觉”“通用 AI 只会摘要”“竞品都做不到”等未经验证的绝对表述。
