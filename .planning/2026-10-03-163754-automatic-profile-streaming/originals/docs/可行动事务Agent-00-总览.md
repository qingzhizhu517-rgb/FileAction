# 可行动事务 Agent · 文档总览

> **一句话**：文启是一个以文件为入口的个人行动助手，帮你理解一份文件对当下的你意味着什么，再把这份意义变成具体行动。**收到文件，先交给文启。**
> **主线**：上传后直接进入 Agent，先总结文件，有沉淀时结合已确认背景形成有依据的个性化解读，缺信息时按需询问，每个文件可多开会话并保留历史，文件沉淀以可编辑卡片自动整理，全局用户档案单独管理；用户可以到此结束，选择继续后再形成可编辑产物。团队与企业属于未来探索。
> **口径依据**：用户于2026年10月2日指定《路演(1).md》为核心项目重点；核心路演稿保留其六段叙事，参赛主线方案承接范围与验收，差异记录说明被取代的旧重点。Document → 可行动事务 → Workflow 是可选行动路径。
> **当前状态**：2026年10月3日已新增本机单用户 MVP，启动入口 `./run.sh`，模型已在后台配置，COS 在页面配置。合成替身流程已测试，`gpt-5.6-sol` 真实模型的合成材料流程已验收，真实 COS 云端读写仍待验收；没有真人访谈或付费记录。旧 Demo、视频和原始 DOCX 是参考资产。赛事来源沿用9月26日读取记录；评委线下试用和账号收集细节仍待官方书面确认。
