# 可行动事务 Agent · 市场调研与验证

> 核查日期：2026-09-26。用户确认最容易触达大学生及校园社团；团队版、企业版均为早期设想。研究覆盖个人记忆工具、校园现有流程、协作平台、公开反馈、变现与验证方法。改进方案见 [[可行动事务Agent-Idea完善方案]]。

> **9月27日处置补充**：沿用上述已存证据，完成产品、技术和官方流程反例复核；未新增联网、访谈或应用实测。具体处理见 [[可行动事务Agent-问题处理与方案审定]]：通知先入、六种材料状态、禁用阻断、选择保存、变更失效及本届范围收紧。下列外部事实和价格仍是9月26日读取快照。

## 1. 结论与本轮真正验证了什么

**值得继续验证的是“校园事务中的个人资料与材料复用”，不宜把三条件学时计算或通用个人记忆作为唯一卖点。** 首个候选任务是竞赛/项目报名材料准备；社团负责人收件与交接是相邻实验，企业暂不作为确定商业路线。

| 判断 | 本轮证据 | 当前结论强度 |
|---|---|---|
| 校园存在多材料、多渠道、带期限的事务 | 高校正式通知明确列出材料、系统、签字、电子/纸质提交 | 已验证流程存在，未验证普遍痛苦程度 |
| 部分材料有再次使用的机会 | 竞赛通知动员既有项目；不同事务都使用项目、成果、名单等资料 | 支持研究复用；不代表原文件可直接再次提交 |
| 通用记忆、引用、任务能力已有竞争 | Mem、通用AI、ima生态、remio、Notion等官方说明 | 已验证功能重叠；未运行同题效果测试 |
| 单纯展示学时分类缺口差异不足 | 高校PU指南已写明分类、最低要求与完成进度 | 对原定位构成直接反证，不能说现有平台只有总量 |
| 新方案比现有方法省事 | 尚无本产品、真人任务对照 | 未验证，必须把首次整理与人工确认时间算进去 |
| 学生付费、社团续用、企业采购成立 | 没有交易、行为或采购记录 | 未验证；不能由竞品价格或学生总人数推导 |

本轮已经执行公开资料阅读、竞品功能对照及真实通知的材料复用分析。未注册试用、未上传个人材料、未访谈用户、未向任何人发送调研消息，以下没有把计划写成实验结果。

| Glean | 所读产品页以联系演示为入口，未取得可比较的公开固定报价 | 不编企业采购价格或收入模型 |

不使用“全国大学生人数×客单价”作为市场验证。首个可服务范围应由**能触达的人中，有目标事务、有必要资料、愿试用且能获得价值的人数**逐层统计；这些分母目前尚无数据。

收费先研究有边界的按次交付；同一付款人确有多次需求后再试任务包或学期方案。社团负责人按周期服务仍是独立假设；使用者、负责人和学校采购方不一定是同一付款人，活动经费也不等同软件预算。

单次贡献按实际净收入扣除解析/模型、存储、重试、支付费用、支持工时和可归属的新增模板维护计算，创始人时间不按零计。固定研发与获客另列，单次贡献为正不等于盈利。当前没有这些交易与成本实测。

## 6. 改进后的机会与风险

| 机会假设 | 需要做到的具体差异 | 最强反证/失败信号 |
|---|---|---|
| 当前任务比通用知识库更容易启动 | 通知先给要求清单，零资料显示个人材料未检查；再按需选文件 | 找文件、输入与确认的总成本超过原方法 |
| 第二次复用减少重复解释 | 记忆能追溯、可纠正，优先只确认变化 | 第二次仍重新上传全部资料或重复填表 |
| 复用边界比单纯找回文件有价值 | 标出用途限制、期限、旧版本和证据不明 | 系统把过期表格、禁重复成果或旧成员当作有效 |
| 社团可形成自然相邻场景 | 一位负责人就能启动，经授权收集具体材料 | 必须全员迁移个人资料，或与学校审批系统重复 |
| 校园模板与纠错记录可积累经验 | 持续记录字段、版本、失败案例及纠正成本 | 维护每校规则和人工支持的成本高于任务价值 |

真正可研究的资产是获授权的任务样本、模板适配、版本维护和纠错经验；当前尚未形成。更多个人文件可能增加个人复用价值，但不自动产生跨用户网络效应。

## 7. 下一轮验证：准备好方法，保留空白结果

### 访谈：回顾发生过的事情

建议先访问6名学生、2名社团负责人，覆盖活跃申请者、低频用户及已有满意工具的人。取得同意后只记录必要且可脱敏信息；以下是提纲，不是已执行访谈。

1. 最近一次申请、评优或报活动是什么？从通知到提交，逐步怎么做？
2. 哪些资料从哪里找到，哪些重复填写，哪里发生补交或找错版本？
3. 打开你当时的文件夹、表格或系统，哪些已经很好用？
4. 哪些步骤一定要本人、负责人或老师确认，为什么？
5. 第二次类似事项发生时，你实际上复用了什么，又重做了什么？
6. 什么资料不愿交给新工具？如果还要再维护一个知识库，你会放弃哪一步？

少问“你是否需要一个AI助手”，多记录过去行为。没有实际耗时记录时写估计，不把回忆分钟数当计时测量。

### 同题对照：包含最强的现有办法

对照组至少包含用户当前流程，以及具备文件、项目上下文/记忆的通用AI；有条件再加入ima或现有校园平台。保留完整任务与背景，用清楚、合理的提示，允许与原型相当的确认步骤，记录产品版本和套餐，不故意给竞品弱提示。

分别测第一次使用与第二次复用；交替任务顺序，使用难度接近的不同题，降低练习效应。找文件、初始化、上传、核对、纠正、可选保存和导出都计时，保留现有方法已有资料的优势。研究者代选文件或解释规则记为辅助完成，失败与已耗时间留在分母，不只报告成功者节时。另测结构化记忆相对保存原文件的增量。

核心指标：完整任务时间、关键遗漏、错误复用、来源可定位、确认负担、第二次新增输入和独立完成率。关键误导不能由速度抵消。材料复用率的分母是实际可复用项；再次使用同时报告全部观察者中的机会发生比例、机会内自然返回率与全体返回人数。失联/未知不归为无机会，提醒后返回另列；机会少本身影响收入频率。

### 首批边界案例

| 案例 | 预期表现 |
|---|---|
| 零个人资料或相关文件读取失败 | 显示未检查及覆盖范围，不能称本次未找到 |
| 旧项目介绍与新比赛主题相关 | 推荐候选内容，并说明不等于资格通过 |
| 适用规则明确禁止，且证实同成果已用于往届获奖 | 该资料与该用途为不可用于本次，普通选用不能解除；缺使用史时为需更新/确认 |
| 去年申请表与今年新模板并存 | 保留版本，提示使用本次模板并核对内容 |
| 未确认的成员名单 | 要求本人/负责人确认，不补造成员 |
| 通知截止时间暂定或年份冲突 | 标明待确认，保留原文，不自动定闹钟 |
| 找到文件，但缺签字或盖章 | 区分“文件存在”与“材料符合要求” |
| 用户纠正/停用后旧响应迟到 | 旧结果先过时，旧响应不得回填；新快照需重新审阅 |
| 个人资料未授权保存或共享 | 不跨事务留存；本届不做多人共享，后续协作须另验证访问边界 |
| 保存后刷新/新建第二个事务 | 读到持久保存的已确认材料，按新用途检查，只复用适用部分，记录额外确认成本 |
| 输出为清单，尚无提交回执 | 保持“待提交/未确认”，不能显示已报名 |

这些用例尚未运行。9月27日已做规格层面的反例复核，详见审定篇及其独立记录。原“4/6独立完成、25%中位节时”仅为待校准讨论信号；下一步先补运行与真实任务证据，不能自动升级为市场通过。
