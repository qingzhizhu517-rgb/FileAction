本轮内容以根目录《路演.md》为准，实际读取日期为 **2026-10-02**；未改写原路演稿。页面仍为前四屏、收尾栏与页脚。

- 桌面、平板、手机自适应，保留移动导航、全局暂停和减少动态效果支持。

## 动效增强

- 首屏标题分段入场、下划线描绘、文件阵列登场与轻微鼠标倾斜；保留上浮粒子、暖黄流动光晕与文件错相浮动。
- 首屏文件依次展示奖学金通知、项目经历、申报指南、与你有关、合作方案、本次积累与可编辑产物。预览说明与后续入口同步对齐路演。
- 向下滚动时首屏短暂吸附，文件按从左到右的次序、自下而上擦除，边缘带金色光线；下方页面从底部上推覆盖首屏。向上滚动可还原，不接管滚轮或自动跳页。
- 短屏先自然滚动至文件完整可见再进入擦除段；系统减少动态效果或禁用 JavaScript 时，文件保持静态、页面按普通文档流浏览。
- 按钮磁吸位移、悬停扫光、点击粒子；导航底部显示阅读进度。
- 第二屏阅读重点随滚动浮现；第三屏个性化解读、第四屏解读传递至选择均在画板进入视口后自动播放。动画是预设呈现，不代表文件解析或模型生成进度。
- 保留底部旋转光环、收尾内容入场及文件预览和原文弹窗。
- 右下角可暂停或恢复装饰动效；系统减少动态效果偏好下关闭新增动态效果。离屏区块、隐藏标签页暂停循环动画，手机减少粒子数量。

## 直接操作的动画

- **点开文件**：悬停抬起、点击放大预览、关闭收回；前后按钮或左右方向键翻阅。预览可进入对应的个性化解读；最后一份进入行动选择。Escape 关闭并返回原文件焦点。
- **聚拢 / 展开**：文件阵列可收拢成居中的一叠，再展开回原位。继续向下滚动会自动展开，接回原来的擦除转场；文件擦除时不再参与鼠标与键盘交互。
- **解读与依据**：三场景切换支持左右方向键、Home、End；依据弹窗支持原文高亮、可选补充、修改笔记与自主保留。
- **选择与产物**：自动播放停在用户选择；点击继续才准备可编辑文本，切换场景或产物保留各自编辑，下载当前文本。
- 暂停或减少动态效果时，预览、场景切换、依据和编辑仍可用；没有 JavaScript 时显示静态内容，第三屏提供奖学金依据折叠区。
- 所有材料与判断均为预设合成示例；补充和保留状态仅在当前页面内存中使用，刷新清除，不建立真实长期记忆。

## 第二屏：从逐段筛选到阅读重点

- 把原先十二份不同文件的整理，改为一份合成奖学金通知的十二处内容。卡片从散落到归位，表达阅读重点被梳理出来。
- “成绩要求／项目成果／综合测评／申请陈述”四处保持强调；其余内容逐渐淡化但仍保留，提示需要时可以回查。四处是本例构图，不是固定分类模板。
- 初始只有标题；随滚动逐层出现具体内容、与本人背景的关系、待核实事项或可选下一步。例如项目成果联系校园调研，综测条件提示可补充或跳过。
- 桌面六列两行、平板四列三行、手机三列四行；短屏先自然滚到画板再吸附。保持原生滚动与反向还原，不强制跳页。
- 全局暂停冻结进度；减少动态效果或禁用 JavaScript 时显示完整静态解读。所有内容和计数为合成示意，不表示真实解析结果。

## 第三屏：解释为什么与你有关

- 标题为“不只说文件写了什么，更解释为什么与你有关。”画板进入视口自动播放约 5.2 秒：文件进入、扫描要求、连接四类理解线索，再展开个性化解读。
- 四个节点分别为文件明确写的、本人确认的背景、还不能确定的、当下想了解的。桌面并排显示关联图与结果，移动端在同一舞台交接。
- 学生示例：奖学金通知联系已完成的校园调研；综测排名和成果认定待核实。教师示例：申报指南联系学习支持研究；资格、限项、成果条件待核实。业务负责人示例：合作方案联系当前调研需求；交付、验收、资源安排待确认。
- 切换或重播场景时同步第四屏上下文。动效按时间推进，不需要继续滚动；完成后保留结果。离屏、后台、全局暂停、打开依据弹窗时冻结，恢复后续播。
- 全局暂停时主动切换场景，直接呈现新解读，仍可展开依据；暂停时点击继续，直接显示可编辑产物。
- 点击“展开依据与相关背景”并排查看合成原文与确认背景，原文重点高亮；另列关联判断与未知，避免把推断写成原文事实。
- 弹窗根据当前场景只问一个影响判断的问题，可补充，也可暂时跳过；确认的补充在首次准备产物时引用，既有产物保留用户编辑。
- 本次笔记从示例文件及交流形成；可以修改、保留当前版本或移除。修改后须再次保留才会更新保留版本，保留仅在本页会话中生效。
- 弹窗支持键盘焦点循环、Escape、关闭按钮与遮罩关闭。所有自填文本按纯文本处理。
- 本屏不吸附、不增加长滚动占位。减少动态效果显示关联图及完整结果；无 JavaScript 显示静态奖学金示例和依据折叠区。

## 第四屏：先选择，再准备产物

- 标题为“读懂之后，是否继续，由你决定。”进入视口自动播放约 3 秒：刚才的解读出现，经连接线传递至用户选择，停在两个操作按钮。
- “只想了解”结束本次准备，不创建新产物；“继续”才展开对应场景的申请陈述草稿、申报核实问题或合作讨论提纲。还可切换核实问题和材料清单。
- 产物沿用相关背景、用户确认补充及主动保留的笔记，均可直接编辑并下载当前 Markdown 文本。下载使用浏览器本地 Blob，不访问模型或上传接口。
- 各场景和产物单独保存本页编辑，切换或停止后再次继续不会覆盖；刷新页面清除。后补充的信息不静默覆盖已有产物，需自行编辑。
- 入场自动播放只演示“解读 → 选择”，不会代替点击继续。普通文档流直接衔接收尾；离屏、后台、全局暂停或依据弹窗开启时冻结。
- 支持重播入场动效，不重置产物或用户选择；减少动态效果直接显示选择并隐藏重播。无 JavaScript 保留静态解读和选择说明，操作按钮禁用。
- 本页是预设合成交互，动画不是模型生成。产物为待本人确认的示例初稿，不代表资格通过、完成申请或已经对外发送。
