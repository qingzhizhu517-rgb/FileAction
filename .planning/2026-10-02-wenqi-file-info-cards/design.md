# 文件信息卡片实施方案

日期：2026-10-02

用户在三种展示方案中明确选择第一种“文件信息卡片”。本轮落实已确认的方案：文件类型图标、完整文件名、格式/大小/上传时间、一句话摘要和关联事务；点击卡片进入既有事务对话，独立“预览原文”按钮在当前页打开既有原文弹层。

摘要为现有六份合成文件的预设内容概括，没有运行真实解析模型。摘要缺失时不生成替代判断，只保留文件基础信息。事务关联从既有事务数据计算，个人简历显示两个事务。

卡片使用原生按钮与独立的预览按钮，避免嵌套交互元素。标题按钮的透明点击范围覆盖整张卡片，预览按钮位于其上方。网格保留三列/两列/单列响应式切换；列表改为紧凑信息行。继续使用用户指定的暖黄色板。

原有搜索、筛选、直接进入对话、引用定位、多事务成果与草稿保留行为沿用。预览在当前页打开，关闭后恢复触发按钮焦点，不自动切换事务。

原始 HTML 与路径清单已保存在本目录。历史快照不改写；上一轮规整缩略图的局部覆盖样式在现行 HTML 中由信息卡片样式取代。外部访问限制仍按已有状态处理，不绕过浏览器保存的阻止设置。
