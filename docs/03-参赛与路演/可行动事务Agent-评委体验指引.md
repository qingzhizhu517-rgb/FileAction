# 文启 · 评委体验指引

## 1. 进入体验

本机打开 [文启首页](http://127.0.0.1:8785/intro/)，点击“上传文件”，登录 `admin`。本机已创建此体验账号，显示名称为“管理员”，目前与普通用户权限相同。密码由准备人员从本机 `var/local-preview/default-account.json` 取得，不写入仓库或公开说明；该账号和密码不会随新克隆自动创建。

登录后进入文件空间，选择“体验预设场景”。确认页可先查看角色、下载 PDF，也可取消。点击“保存示例并进入”将准备文件、目标与合成背景，不会自动发送给模型。

也可选择“也可以用自己的文件”：支持 TXT、Markdown、文本 PDF、DOCX，最大10 MiB。原件保存到腾讯云北京地域的文件空间，模型发送前再核对范围，无需选择存储方式。扫描 PDF 的 OCR 不在本轮验收范围。

## 2. 建议体验顺序

1. **读懂通知**：预设为虚构“校园创新实践计划”，角色是大二学生、独自参加、每周6小时、只有想法。点击“预览外发内容”，核对文件、背景、问题和模型服务方，再确认发送。模型真实生成解读，不是预置回答。
2. **核对依据**：查看原文截止时间、倒计时、日程和演示入口，展开一个“文件来源”，对照原文与本次背景。文件事实、背景、系统推断和未知分别呈现。
3. **修改背景再追问**：在“文件背景卡片”把每周6小时改为12小时，并补充“已有一张纸面原型、尚未做用户访谈”，保存后提问“按最新背景，最需要先补齐什么？”。外发预览会读取最新已保存背景。
4. **自主选择下一步**：可点击“到这里就够了”结束本次理解；若继续，选择“其他草稿”，要求起草一页项目说明，包含问题、目标用户、解决思路和两周验证计划，再确认发送。
5. **带走自己的版本**：打开“编辑与下载”，添加自己的补充并“保存为新版本”。模型 v1 与用户 v2 分开保留。点击“下载此版本 Markdown”；若未开始，使用出现的保存链接或“复制导出内容”。复制内容含服务端附带的来源与未知说明。
6. **返回继续**：回到文件空间，在“最近阅读”重新进入当前会话，可恢复有效解读、引用、消息和成果；也可重新启动示例，获得一段独立的本次会话。

本机 `admin` 当前已有一段实测会话，标题为“合成体验 · 校园创新实践计划”，已生成、编辑一页项目说明 v2。它依赖当前登录会话；重新登录后请从“体验预设场景”开始，不承诺旧临时会话仍然存在。

## 3. 真实性与保存边界

- 示例 PDF、机构、人物背景、日期与报名入口全部为合成材料；`example.org` 入口不提供真实报名功能。准备清单或草稿不代表已报名、已提交或资格通过。
- 本机真实模型配置为 `deepseek-flash`，服务地址为 `api.deepseek.com`；失败会明确显示，不回放固定答案。每次调用需确认所选材料的外发范围。
- 文件原件保存在文件空间；消息、解读、文件背景卡片和草稿目前属于当前登录会话，有临时期限。退出或结束本次会清理临时内容。整工作区跨登录长期保存尚未实现。
- 用户长期背景独立保存，须主动决定保留和复用；回答问题或确认事实不会自动写入长期个人档案。
- 2026年10月3日已实际完成云端 PDF 上传、三次真实模型调用、背景修改、引用核对、v2 编辑、刷新及重新打开、导出内容复制和桌面/手机布局检查。此次内置浏览器取消 Markdown 下载，因此文件实际落盘未列为通过；评委使用的实际浏览器须复验该步骤。
- 当前服务监听本机，尚未公网部署。源码不含模型密钥、COS 密钥、账号密码和运行数据库。

## 4. 准备人员检查

按 [README](../../README.md) 启动前端、API 和生成处理进程，确认本机模型配置与 COS 配置已载入。当前桶使用显式 `immutable_key` 模式，无需开启版本控制。新环境应重新准备自己的账号和私密配置。

合成材料位于 `front/public/examples/campus-innovation-synthetic.pdf`；体验入口会按原件字节校验是否可复用，不替换用户原有资料。预设角色与目标可在页面修改。
