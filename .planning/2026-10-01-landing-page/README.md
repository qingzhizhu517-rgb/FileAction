# 文启 FileAction

丢一份文件，它站在你的角度读给你听：跟你有什么关系，要不要做点什么。

文启是西客松 XiHack 2026「可行动事务 Agent」的参赛方案库。内核是 **Document → 可行动事务 → Workflow**：

- **个人版**：读文件时带上你的经历、意向和用过的材料，主动发现哪些能复用、哪些不能用；每条匹配都能回到原文，并直接列出缺项与截止、起草缺的材料。只在当前事务需要时索取信息，不要求先建档。
- **团队版**：临时组队时按每位队友的能力推荐分工、指出能力缺口，不做监督。
- **企业版**：路线图，尚未验证。

## 当前状态

本仓库目前只有方案文档和赛前资料，还没有赛中代码、真人访谈或付费证据。

- `05-交互Demo/` 是 2026年9月30日的赛前交互设计稿，对应旧方案，使用规则模拟，没有接入模型，参赛时如实申报。
- `06-讲解视频/` 是概念讲解动画，画面为合成示意，不是产品实录；片中仍是旧名“旁批”。
- 本届成果须在官方 67 小时开发窗口内完成。

## 运行赛前交互设计稿

需要 Python 3 和 Node.js，没有第三方依赖。

```sh
python3 05-交互Demo/serve.py                    # 只监听本机，浏览器打开 http://127.0.0.1:8765/
node --test 05-交互Demo/tests/engine.test.mjs  # 规则测试
```

素材全部为合成数据，页面不会把资料发送给外部模型。使用方法见 [交互Demo使用说明](05-交互Demo/可行动事务Agent-交互Demo使用说明.md)。
