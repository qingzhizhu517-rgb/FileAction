# 可行动事务 Agent · 可行性分析

> 当前推荐见 [[可行动事务Agent-Idea完善方案]]；市场事实见 [[可行动事务Agent-市场调研与验证]]。学时核对是备选技术方案，团队与企业是独立假设。

## 一、当前判断

**校园个人事务与材料复用值得做一个小范围验证原型。** 所需文件解析、检索、结构化候选、来源定位及文件导出可由现有技术组合实现；最大不确定性是含人工确认在内是否真的比现有方法省事。

用户可接触大学生和校园社团，这是验证渠道条件，尚不是需求或付费证据。公开通知证明相关流程存在，竞品证明通用能力已有供给；两者共同支持把问题缩到一件具体事务，而不是直接建设通用个人信息平台。

## 二、各维度的证据与缺口

| 维度 | 已知依据 | 尚待验证 | 当前处理 |
|---|---|---|---|
| 用户任务 | 官方通知确有项目书、证明、签字、多渠道和期限 | 目标学生具体在哪一步付出额外成本 | 回看最近真实事务，包含已有满意工具的用户 |
| 竞争 | 个人AI和协作平台已有记忆、引用、任务与产物 | 我们在同题流程上的实际优势 | 比较初始化、确认、纠正与第二次复用的总成本 |
| 数据 | 部分通知公开，旧项目文件可由本人提供 | 用户愿提供哪些资料、格式是否稳定 | 仅收当前任务所需；合成案例不能证明真实适配 |
| 技术 | 单一通知+少量资料的受控流程可实现 | 模糊规则、引用、版本与异常稳定性 | 抽取候选、人工确认、保存来源与变更，不自动裁决复杂资格 |
| 记忆价值 | 旧项目和成果可能服务后续事务 | 第二次是否少找文件、少重填 | 演示和试点均包含第二次任务，检验需更新和不可复用项 |
| 协作 | 社团有周期申报、材料链和负责人 | 是否存在成员催收/换届交接痛点，新工具是否减少重复建设 | 一位负责人启动，按事项共享，不要求全员建档 |
| 变现 | 竞品有免费与付费供给 | 付款人、转化、频率和支持成本 | 不定死个人订阅或企业采购路线 |
| 参赛交付 | 正式开发67小时、5+3展示 | 实际成员能力、可投入时间和样本复杂度 | 三个工作面、一条主线；预留联调、休息和封包 |

## 三、技术最容易被低估的部分

1. **材料存在不等于适用。** 需要核对用途、版本、期限、成果重复使用限制和签字状态；找不到依据就保留未知。
2. **记忆会过期。** 个人意向、成员名单和成绩时点不同，不能把一次抽取永久当真；纠正后应检查受影响事项。
3. **确认成本可能吞掉收益。** 全量建档、标签维护、反复让人校对每个字段都会增加负担；首版只处理当前任务必需内容。
4. **“无痛输入”有接入代价。** 首版采用上传或粘贴，不假定可以自动读取任意微信、邮箱、学校系统；格式扩展按样本收益决定。
5. **可追溯不等于正确。** 引用可能误读或适用范围错误；模型生成JSON正确不代表判断正确。文件内容不得作为系统指令执行。

不必先上复杂知识图谱、多Agent编排或通用规则编译器。少量可查看的事实、意向、来源关系和事务快照即可验证核心假设；用户界面不需要暴露这些技术名称。

## 四、赛中最小范围与降级

完整建议见完善方案。先支持一类可读取通知、少量旧资料、候选要求、来源检查、可纠正记忆、复用边界和实际清单。复杂资格交给人工，不把材料齐全当作报名通过。

| 出现的问题 | 合理调整 |
|---|---|
| 找不到合适的真实样本 | 使用标注清楚的合成案例验证逻辑；市场有效性仍未验证 |
| 文件解析不稳定 | 缩减版式和格式；允许明确披露的人工核验输入，不能伪称现场全自动 |
| 判断依赖未给出的规则 | 输出待核实内容，保留原文；不把所有不确定项涂绿 |
| 功能来不及 | 减界面和自动化；保住真实输入、来源、一次纠正、第二次复用及可打开产物 |
| 导出仅有索引 | 如实称材料索引或清单，不称完整提交包 |
| 服务现场失败 | 使用封包前提交并明示的备用录屏，说明实际完成范围 |

若选择学时备选，则整体采用其规格和脚本，不将两个不同场景各做一半。其合成128总量、18分类缺口及四态校正保留；不能证明材料复用或真实学校接入。

## 五、市场验证现在可以做什么

公开调研已经完成，本轮不再把全部市场工作推到赛后。赛前可观察真实流程、比较官方通知、了解用户已有办法、核实可取得的样本，并准备方案草图。

原型后再执行真实任务对照和第二次使用观察。6名学生、2名负责人是首轮招募建议，不是代表性样本；25%节时等数字是事先可讨论的内部判据，尚无测量结果。实验提纲、边界案例和分母见市场调研篇。

学校现有系统已经顺畅完成任务、学生不愿提供必要资料、或确认成本高于节省时间，均是需要收缩方向的证据。不得因个人侧证据弱就直接宣布企业版更有价值。

## 六、成本、权限与商业探索

比较单次结果的完整成本：模型与解析、存储、重试、人工复核、支持与规则维护。高频留存不是自然发生的，应按实际申请/活动周期观察；没有第二次机会不能简单判为流失。

团队共享从具体事项和经成员确认的材料开始，个人记忆默认私有。原型接触真实信息前说明用途、接入模型、必要字段及保留方式；多用户访问、撤销授权和清理机制必须随实际部署落实。

企业版需要独立确认岗位、任务触发、现有系统、预算负责人与接入成本；首版不承诺企业级治理、采购或所有员工的统一记忆。

## 七、赛事边界

正式开发为2026年10月1日14:30—10月4日09:30，共67小时；1–5人；正式5分钟展示＋3分钟问答。该窗口包含休息、活动和提交，不是净编码工时。

赛前研究、通用准备和草图可以进行，已有组件与本届新增须分开说明。首晚60秒团队视频与最终录屏分开，最终封包及备用录屏在10月4日09:30前完成。交付建议、评分未定事项及成果权益条款以 [[可行动事务Agent-西客松参赛对齐]] 为准。
