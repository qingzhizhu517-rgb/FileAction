# 可行动事务 Agent · 文档总览

> **一句话**：文启是一个以文件为入口的个人行动助手，帮你理解一份文件对当下的你意味着什么，再把这份意义变成具体行动。**收到文件，先交给文启。**
> **主线**：结合已确认背景形成有依据的个性化解读，缺信息时按需询问，沉淀可查看、修改并由用户决定是否保留；用户可以到此结束，选择继续后再形成可编辑产物。团队与企业属于未来探索。
> **口径依据**：用户于2026年10月2日指定《路演(1).md》为核心项目重点；核心路演稿保留其六段叙事，参赛主线方案承接范围与验收，差异记录说明被取代的旧重点。Document → 可行动事务 → Workflow 是可选行动路径。
> **当前状态**：本分支已实现本地个人 MVP 工程与合成数据测试，并通过真实模型合成通知的浏览器冒烟；个性化解读质量、真人使用及公网仍未验收，没有真人访谈或付费记录。实际结果见开发验证记录。旧 Demo、视频和原始 DOCX 是参考资产。赛事来源沿用9月26日读取记录；10月1日团队获知的评委线下试用和账号收集形式，仍待官方书面确认。
