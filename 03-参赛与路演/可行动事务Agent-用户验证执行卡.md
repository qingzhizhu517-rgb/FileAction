# 可行动事务 Agent · 用户验证执行卡

导航：[[可行动事务Agent-00-总览|文档总览]] · [[01-产品方案/可行动事务Agent-参赛主线方案|参赛主线方案]] · [[03-参赛与路演/可行动事务Agent-路演答辩应答卡|路演答辩应答卡]]

> 用途：开赛前（10月1日14:30前）完成3名种子用户的回顾访谈与截图门槛。原则是看行为，不看表态：不问“你需不需要”，只还原真实发生过的事。

## 1. 找谁

一学期内参加过2次以上竞赛或申报、并且临时组过队的同学。优先找最近一个月刚准备过材料的人。不找队友本人，避免自己人给出偏向的回答。

## 2. 邀请话术

```text
我们在做一个比赛项目，想了解大家准备竞赛/申报材料的真实过程。
不推销、不做问卷，大概 15 分钟：请你打开上次准备材料的文件夹或聊天记录，
带我们回顾一下当时是怎么做的。记录会脱敏，不留你的姓名和原始文件。方便吗？
```

## 3. 回顾访谈提纲（约15分钟）

开始前说明：只记录必要且脱敏的信息，对方可以随时跳过任何问题。

1. 最近一次准备的是哪个竞赛或申报？请打开当时的通知。
2. 从收到通知到提交，你第一步做了什么？接着呢？（让对方边翻文件边讲）
3. 哪些材料是从以前的文件里找出来的？花了多久？（没有计时就记为“回忆估计”）
4. 有没有用错材料、版本不对、缺签字，或者被退回过？当时怎么发现的？
5. 你判断“这份材料能不能用”时，依据的是什么？
6. 组队时，你怎么知道队友擅长什么？分工是怎么定下来的？
7. 这次准备时，你有没有用过 AI 工具？用在哪一步，哪里不好用？

不要问：“如果有一个 AI 帮你做这些，你会用吗？”“你愿意付多少钱？”这类问题只能得到想象中的回答。

## 4. 截图门槛

访谈结束时提出：

```text
如果你手头正好有一份正在准备的通知，愿意截图发给我们吗？
我们会用它测试产品，不会外传，测试完删除。不方便也完全没关系。
```

愿意发来的人记为核心用户。发出人数和邀请人数都原样记录。

## 6. 路演怎么报

- 只报真实数字，例如“访谈 3 人，其中 2 人讲到用错材料的经历，1 人发来了真实通知截图”。
- 人数少就照实说，不能外推成比例或市场规模。
- 原话脱敏后引用；没有做访谈就说没做。

## 7. 赛后付费测试（计划）

给正在准备申报的同学提供一次真实的材料对照，付小额费用才能使用。记录邀请人数、实际付款人数和使用后的反馈，口头愿付与实际付款分开记录。金额与规模待赛后确定，当前未执行。
