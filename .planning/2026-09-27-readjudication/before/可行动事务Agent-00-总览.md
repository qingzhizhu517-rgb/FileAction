# 可行动事务 Agent · 文档总览

> **愿景**：让个人资料、经历和意向在下一件事情到来时继续有用。
> **当前推荐**：从大学生的竞赛/项目报名材料准备切入，验证“新通知＋旧资料→可复用内容、待更新材料和下一步”。用户可触达大学生与校园社团；团队、企业均为可选假设。
> **证据状态**：已完成公开市场调研和官方流程对照；尚未实现产品、进行用户实验或取得付费。推荐方案不等于用户已确定全部路线。

## 3. 本轮为什么调整

原草稿强调低摩擦输入、白盒记忆、个人意向和旧材料复用。此前学时核对收敛有助于技术规格，却没有充分体现第二次使用的价值。

公开调研发现：现有个人AI已具备记忆和行动；校园二课平台已有分类进度；真实校园通知则存在材料、版本、签字和多渠道准备工作。因此推荐验证具体的材料复用体验，避免以“别人只会总结”支撑差异。

学时备选仍保留此前纠错：合成分类和128、已知分类缺口18、假设创新+10后138/22/0；已确认0不等于缺证，部分覆盖不等于完整认定。材料准备状态与资格四态分开维护。

## 4. 当前行动顺序

| 阶段 | 主要动作 | 证据或产出 |
|---|---|---|
| 已完成桌面调研 | 阅读官方产品、校园流程和公开反馈；比较三份通知材料 | 有日期和来源的研究结论，不冒充访谈 |
| 赛前问题核实 | 接触学生/社团，回看最近一次真实事务；了解公开资料、画方案 | 确认实际步骤、已有好方法和首个样本；不提前完成参赛核心作品 |
| 赛中原型 | 一条材料准备链、少量可控记忆、第二次复用、实际清单 | 正式67小时内完成并记录本届新增；如实标注数据与人工环节 |
| 原型后验证 | 与本人现有方法及通用AI对照，再观察下一次事务 | 完整耗时、错误、纠正负担和复用行为 |
| 商业探索 | 识别付款人、支持成本及可行收费方式 | 团队/企业路线按独立证据选择 |

正式评审5分钟展示＋3分钟问答；首晚另有60秒团队视频。推荐材料主线脚本在完善方案，原180秒学时脚本仅作备选。官方节点及未定条款以参赛对齐篇和后续公告为准。

## 5. 维护约定

新推荐方案以完善方案、定位决策和产品定义为主；市场论据集中维护在调研篇。学时技术文档只约束其备选场景。更新一条决策时同步导航、速览、答辩及相关范围说明，避免两套主线同时生效。

真实制度优先于演示样例；所有假设、计划、厂商声明、桌面核查和用户实测分别标明。完整规范见 [[AGENTS]]。
