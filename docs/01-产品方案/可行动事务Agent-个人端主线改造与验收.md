# 文启个人端主线改造与验收

## 1. 范围和依据

本轮按用户确认顺序，在当前 `main` 工作区引入 `origin/codex/personal-mvp-design` 的前后端实现，并对照[[docs/03-参赛与路演/可行动事务Agent-核心路演稿|核心路演稿]]修正个人端主线。开发分支导入基线为 `e852d1b`，主分支基线为 `0e892fa`；此前未提交；用户现已授权按轮提交并推送 main，实际提交以 Git 记录为准。未完成公网部署。

宣传页仍由 `frontend/` 维护，保留合成示例与既有资产标识。正式前端 `front/` 使用同一品牌视觉，`/intro/` 是唯一完整首页，`/` 自动进入该页面；上传入口进入真实产品，生产构建包含宣传页资源。原先另建的简化首页已移除，产品 Logo、登录页和服务失败页均回到完整首页。

## 2. 已落实的行为

| 环节 | 本轮行为 |
|---|---|
| 文件入口 | 首页突出上传；上传后打开临时阅读工作区，不自动调用模型。文件管理降为次级入口。 |
| 理解与核对 | 解读区分文件事实、已确认背景、系统推断和未知；引用窗口并列展示原文与该判断实际引用的背景。 |
| 对话承接 | 后续请求读取最新消息，在外发预览展示实际历史。最多保留最近连续12条、48,000字符。 |
| 补充 | 缺信息时允许回答、上传或跳过；超过3项时按需展开，交流历史折叠。 |
| 阅读完成 | “到这里就够了”显示完成并收起补充和输入；不自动删除内容、不强制生成行动。 |
| 本次沉淀 | 背景候选可修改确认，默认仅本次；长期保留单独勾选，未保存的编辑不能误保留旧版本。 |
| 背景复用 | 所选已确认背景保存为独立快照；下次主动选择，携带所见版本；停用、过期或来源失效项不能复用。 |
| 具体产物 | 选择继续后，可选材料清单、待核实问题、申请陈述、合作提纲或其他草稿，再单独确认模型外发。 |
| 编辑与下载 | 工作区内打开成果，模型原稿与用户修改按版本保留，下载指定已保存版本。 |

后台补齐独立背景的真实存储、版本、同意回执、幂等和复用接口；新增 `0007` 迁移。旧冻结 SQL 正文未改，初始迁移仅修复 LF/CRLF 校验兼容。补齐 SQLAlchemy 异步依赖。

## 3. 实际验收

验收日期为2026年10月3日。使用明确标注的合成通知和合成个人背景，无真实用户材料，无真人访谈、付费或业务效果主张。

### 3.1 浏览器与真实模型

在 `http://127.0.0.1:8785/` 实际走通：

1. 公共首页 → `/intro/` 原宣传页 → 产品登录与文件空间。
2. 上传合成 TXT，默认临时使用，进入阅读工作区；空文件显示明确错误。
3. 添加已确认合成背景，预览展示文件原文、背景及模型服务方；取消预览不创建运行。
4. 在明确确认范围后调用本机已配置的 `deepseek-flash`（`api.deepseek.com`），收到真实解读。模型区分相关性与资格通过，引用能回到原文及本次背景。
5. 勾选背景保留，真实接口返回成功；第二个工作区主动选择该背景，加入后没有自动调用模型。
6. 选择“到这里就够了”显示完成；继续后选择材料清单，预览确实包含前轮问题与回复。
7. 真实模型生成合成资助材料清单，编辑追加“我的补充（合成验收）”，保存为 v2。浏览器下载的 Markdown 文件实存于本机下载目录，4,179字节，包含用户追加内容及待核实项。
8. 390×844手机宽度检查首页、宣传页、工作区，页面滚动宽度等于视口390，无横向溢出；之后恢复默认桌面视口。
9. 收尾补验：勾选背景后编辑但不保存，长期保留按钮禁用；真实生成期间可打开并关闭沉淀窗口。新一轮真实解读完成后，选择“到这里就够了”，问题输入与待补充区域收起，解读仍可查看。

这只证明本轮合成输入的流程可用，不代表模型在所有文件和场景中准确。

### 3.3 首页统一修复

用户反馈从宣传页进入上传后，点击 Logo 只返回第一屏。根因为 `/` 的 React 简化首页与 `/intro/` 的完整宣传页并存。现保留完整宣传页为唯一首页，旧根入口与 `/index.html` 跳转至 `/intro/`，产品返回链接使用整页导航，重新初始化完整动效。

相关回归测试先出现5项预期失败，修复后相关9项通过；最终前端全量14个文件、74项通过，类型检查与生产构建通过。开发与生产预览均核验了首页跳转、完整章节和产品入口资源。浏览器实际走通“完整首页 → 上传文件 → 文件空间 → Logo → 完整首页”，第二屏文件解读随滚动出现。修改前快照、测试日志与截图位于 `.planning/2026-10-03-140018-unified-home/`。
