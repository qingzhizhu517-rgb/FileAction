# 文启 FileAction · Logo 设计说明

导航：[[可行动事务Agent-00-总览|文档总览]] · [[01-产品方案/可行动事务Agent-参赛主线方案|参赛主线方案]]

## 1. 设计主题：对页

**两片对页，打开理解。** 两个镜像几何面之间保留透明页隙，以展开关系呼应“文启”。左片为暖黄，右片为深黄；统一圆弧与厚实体保持亲和和稳定。图形不逐项解释产品功能，结合字标承载“从文件开启行动”的品牌含义。

V2 比较了“开口 W”“双页”“启口”三款草图，采用双页并命名为“对页”：W 偏柔软且通用，启口容易产生功能图标感；双页的外轮廓和中央负形更完整。以上为本次设计判断，不代表用户验证结果。

独立图形使用 128 × 128 视口，中央透明页隙宽 8 个单位，即视口宽度的 1/16。两片均为实体路径，单色时依靠同一透明间隙分隔。

## 3. 配色与使用

| 角色 | 色值 | 处理 |
|---|---|---|
| 识别主色 | #F6C945 | 左片几何面 |
| 强调深黄 | #E6AD19 | 右片几何面 |
| 中文字标 | #2B2B2B | “文启” |
| 英文辅助字标 | #6B6B6B | FileAction |
| 浅黄、暖白、卡片白 | #FFF7D6 / #FFFDF8 / #FFFFFF | 承载背景 |
| 边框 | #F1E7C8 | 预览页分隔 |

- 独立图形建议从 24 px 起使用；16 px 用于紧凑位置时，注意让中央页隙保留至少一个完整像素。
- 等比缩放，不裁切 SVG 视口。图形外的内部留白已包含在视口中；外部与邻近内容建议另保留至少图标宽度的 1/8。
- 横版包含两行字标，建议以不低于 64 px 的整体高度使用。更紧凑的导航栏可使用独立图形配页面中的品牌文字。
- 浅色背景使用彩色主标；深色背景使用白色单色标。以 img 引入单色 SVG 时，页面 color 不会传入 SVG，可用 filter: brightness(0) invert(1) 转为白色。
- 需要同页多次内联 SVG 时，为每份 SVG 的 title、desc 及 aria-labelledby 引用设置独立 ID，避免重名。

前端引用示例（将 SVG 复制到应用的静态资源目录后调整路径）：

~~~html
<img src="/assets/可行动事务Agent-Logo.svg" width="32" height="32" alt="文启">
~~~
