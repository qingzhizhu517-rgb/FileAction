# 可行动事务 Agent · 文启宣传页

导航：[[可行动事务Agent-00-总览|文档总览]] · [[01-产品方案/可行动事务Agent-参赛主线方案|参赛主线方案]]

## 打开页面

直接用浏览器打开本目录的 `index.html`，无需安装依赖或构建，也可以从仓库根目录启动：

```sh
python3 -m http.server 8787 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8787/07-宣传页/
```

## 页面内容与交互

- 暖黄色品牌首屏、大标题与七份错落排列的文件，手机端精简为五份；低对比文字背景随鼠标轻微偏移，标题区域保留留白。
- 第二屏展示十二份杂乱散落的合成文件，随着继续下滑逐渐转正、移动并归位成整齐阵列。
- 第三屏以“机会雷达”展示新通知进入后关联旧 Idea、获奖经历、求职意向与已确认材料，并展开匹配理由、已有材料和缺项。
- 第四屏以“材料核验台”展示旧材料展开、来源与版本核对、使用记录和本次规则对照，逐项呈现可用、要处理、本次不能用，并可打开合成原文回溯。
- 第四屏后直接进入最后的“让下一份文件，成为下一步的开始”收尾栏，保留完整 Demo 入口与页脚。
- 顶部及移动端导航分别指向文件整理、机会发现、可信复用和收尾栏；机会雷达保留三类通知切换，支持左右方向键、Home、End。
- 原产品价值卡片、详细体验工作台、个人记忆星图、团队规划及常见问题栏目已移除；独立高保真交互 Demo 仍可从收尾栏进入。
- 桌面、平板与手机自适应；移动端导航、滚动渐入、减少动态效果偏好支持。
- 动态文字层在指针停止、首屏离开视口或标签页隐藏后停止绘制；减少动态效果偏好下保持静态背景，触屏不跟随指针。

## 动效增强

- 首屏标题分段入场、下划线描绘、文件阵列登场与轻微鼠标倾斜；保留上浮粒子、暖黄流动光晕与文件错相浮动。
- 首屏文件依次展示竞赛通知、项目介绍、获奖证书、想法、实习简章、个人简历和行动清单。可以打开合成预览，不接收真实上传。
- 向下滚动时首屏短暂吸附，文件按从左到右的次序、自下而上擦除，边缘带金色光线；下方页面从底部上推覆盖首屏。向上滚动可还原，不接管滚轮或自动跳页。
- 短屏先自然滚动至文件完整可见再进入擦除段；系统减少动态效果或禁用 JavaScript 时，文件保持静态、页面按普通文档流浏览。
- 按钮磁吸位移、悬停扫光、点击粒子；导航底部显示阅读进度。
- 第二屏文件整理和第四屏材料核验随滚动推进；第三屏雷达关联进入视口后自动播放。均为预设示例呈现，不代表真实解析进度。
- 保留底部旋转光环、收尾内容入场及文件预览和原文弹窗。
- 右下角可暂停或恢复装饰动效；系统减少动态效果偏好下关闭新增动态效果。离屏区块、隐藏标签页暂停循环动画，手机减少粒子数量。

## 直接操作的动画

- **点开文件**：悬停时文件抬起并扫光，点击后从原位置放大为预览，关闭时收回。预览中可用前后按钮或左右方向键翻阅七份示例；后续入口根据文件跳转到机会发现、可信复用或最后的 Demo 收尾栏。Escape 关闭并返回原文件焦点。
- **聚拢 / 展开**：文件阵列可收拢成居中的一叠，再展开回原位。继续向下滚动会自动展开，接回原来的擦除转场；文件擦除时不再参与鼠标与键盘交互。
- **通知与判断**：机会雷达切换三类通知，材料核验台可查看原文并切换依据核实状态。
- 暂停或减少动态效果时，预览、通知切换与原文操作仍可用，装饰性变形和循环动画停止。没有 JavaScript 时显示静态内容，第四屏原文可通过折叠区阅读。
- 文件内容与关联均为预设示例，不会建立或保存真实个人记忆。

## 第二屏：从散落到有序

- 位置紧接首屏，在机会雷达之前。首屏底部“向下滚动，开启下一页”入口跳转至此。
- 十二份文件以不同位置、倾角、叠放次序散落在画板上，初始卡片只显示文件标题。继续下滑时，画面短暂吸附，文件按错开的进度转正并移动归位，对齐参考线与进度条同步显现。
- 标题逐渐上移，标题下方的具体解读按各文件自身的归位进度分三层出现：与你的关联或可复用内容 → 判断依据或待核实事项 → 建议下一步。文字以淡入、轻微上移和逐行揭示呈现，不使用假文字横线代替解读。
- 文案分别体现主动发现、可信复用、直接行动。例如“项目介绍”依次显示“项目背景可复用”“已确认版本 v2”“起草参赛简介”；“获奖证书”提示本次认定范围待核，“申请草稿”保留模型初稿待确认的状态。
- 桌面为六列两行，平板为四列三行，手机为三列四行；十二份文件始终保留。短屏先自然滚动至画板完整可见的位置，再进入整理段。
- 动画进度直接对应滚动距离，不接管滚轮或自动播放。向上滚动时文字按相反顺序收起，最终回到只显示标题的散落构图；归位后继续下滑进入机会雷达。
- 暂停动效时冻结当前构图和文字显现进度，恢复后同步当前滚动位置。系统减少动态效果或禁用 JavaScript 时直接显示整齐阵列及完整解读，按普通文档流浏览。
- 文件、解读和整理计数均为预设合成示意，不代表真实文件解析、分类或处理进度；画面明示“预设合成解读 · 未接入模型”。

## 第三屏：主动发现与你有关的机会

- 位置紧接第二屏文件整理，在可信复用之前，标题为“新机会来了，你过去的积累，亮了。”
- 画板刚进入视口便自动播放约 5.2 秒的完整动效，无需继续滚动：先由新通知轻微落入中央，再由暖黄雷达扇面扫过，四类已保存背景错峰亮起，曲线从通知向相关背景逐段连接；最后桌面星图向左让位，右侧展开机会卡片。平板与手机在同一画板内由星图交接至结果卡片，避免挤压内容。
- 机会卡片逐层解释“为什么可能适合你”，给出合成示例中的判断依据，并列出已有材料、缺项与待处理事项。竞赛示例将无障碍地图构想连到社会服务赛道，可复用项目介绍 v2，仍需起草参赛简介、更新本届签字名单。
- 三个通知按钮可切换竞赛、奖学金、实习示例，也支持左右方向键、Home、End。不同通知点亮不同积累：竞赛关联 Idea；奖学金关联获奖记录和成绩单；实习关联已确认求职意向与调研经历。不直接相关的背景保留低亮度，需要核对的内容用提示色显示。
- 关联理由不替代资格判断：往届获奖成果不可按示例规则重复申报；奖学金证书认定范围和综测排名仍待核实；实习到岗安排仍待确认。竞赛与奖学金的后续按钮跳转至材料核验台，实习按钮跳转至完整 Demo 收尾栏。
- 动效进度由时间驱动，不随下滑推进或回滚倒放。播放完成后保留结果；点击任一通知按钮可切换或重播。画板离开视口、页面进入后台或点击暂停时冻结，返回可见或恢复后从原进度继续，不跳到结尾。
- 本屏取消吸附和额外滚动占位，按普通文档流直接衔接第四屏；短屏也无需滚过长距离才能离开。系统减少动态效果时直接展开关联图与完整结果；无 JavaScript 时保留静态竞赛示例，通知切换保持禁用。
- 全部背景与通知均为预设合成示例，画面明示“预设合成示例 · 未上传文件或调用模型”；进入动画是交互设计，不代表真实上传、检索或模型分析。

## 第四屏：可信复用旧材料

- 紧接第三屏机会雷达，标题为“旧材料，能不能再用？每个判断，都有来处。”延续暖黄主色，以柔和绿、琥珀、陶红及文字符号区分三种判断。
- 滚动开始时三份材料叠放在画板中央；继续下滑，桌面向三列展开，平板与手机向三行展开。来源、版本和使用记录依次显现，暖黄扫描光带经过画板，上方四个核对维度逐个点亮，最后三种判断错峰落印。向上滚动可沿原路径收回。
- 项目介绍 v2 的已确认背景可用于起草；旧成员名单需按本届信息更新、重新签字；往届获奖成果同时命中本次禁用条款和已获奖事实，因此不能用于本次作为新成果申报。可用仅限已检查的要求与指定用途，不代表资格通过。
- 点击“看原文”打开对应判断的依据弹窗：并排展示通知条款与材料或记录原文，关键片段高亮，附版本核对、使用记录及判断范围。手机纵向展开，弹窗支持滚动、Escape、关闭按钮与遮罩关闭，关闭后返回原按钮焦点。
- 禁用示例附“少一项依据，判断会怎样？”互动实验。可以分别将明确禁用条款、对应获奖事实设为待核实；缺少任一依据时，实验结果变为“要处理”，不会直接推断禁用或可用。实验不修改原示例资料和主画面判断，重新打开会复位。
- 动画进度直接对应原生滚动，不接管滚轮；暂停时冻结当前构图，恢复后同步滚动位置。短屏先自然滚动至画板完整可见后吸附。系统减少动态效果时显示完整静态结果；无 JavaScript 时保留三态卡片及可展开阅读的合成原文，“看原文”弹窗按钮保持禁用。
- 原文只维护在 HTML 的同一份静态内容中，弹窗从该内容生成。通知 § 3、版本和历史使用说明均为本次设计补充的合成示例，不是外部事实或真实核验。画面持续标明“预设合成示例 · 非真实核验”。

`index.html` 维护页面结构与文案，`styles.css` 维护样式和断点，`app.js` 维护首屏背景、导航与入场，`motion.css` 与 `motion.js` 维护增强动效，`file-scroll.css` 与 `file-scroll.js` 维护文件阵列及首屏擦除转场，`interactions.css` 与 `interactions.js` 维护文件预览与聚拢，`file-organize.css` 与 `file-organize.js` 维护第二屏散落文件的滚动归位场景，`opportunity-radar.css` 与 `opportunity-radar.js` 维护第三屏机会雷达、通知切换与关联结果。旧版扩展栏目的脚本按对应结构是否存在决定初始化，精简页面不启动这些模块。使用系统字体、内嵌 SVG 和 Canvas，无外部字体、图片、脚本或模型依赖。

`trusted-reuse.css` 与 `trusted-reuse.js` 维护第四屏材料核验台、滚动展开与三态落印、原文弹窗及两项依据的互动实验。
